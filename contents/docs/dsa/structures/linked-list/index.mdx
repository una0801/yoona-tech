### ◾️ 기능
  <ul><li>Node : 데이터의 저장 단위로, 데이터 값 + 포인터로 구성</li></ul>
  <ul><li>Pointer : 각 노드 안에서, 다음이나 이전의 노드 주소를 가지는 값 의미</li></ul>

☑️ 장점 : 미리 데이터 공간을 할당할 필요가 없음

☑️ 단점 : 연결을 위한 별도 데이터 공간이 필요하므로 효율이 낮음
        데에터를 찾는데 접근성이 안좋아 성능이 느림
        중간 데이터 삭제 시, 앞 뒤를 모두 고려하여 재구성하는 코드 작성 필요

### ✏️ 기본 `list` 를 활용한 배열 예제

<Tabs defaultValue="python" className="pt-5 pb-1">
  <TabsList>
    <TabsTrigger value="python">Python</TabsTrigger>
  </TabsList>
  <TabsContent value="python">
    ```python
      # 리스트를 사용한 배열 예제
      arr = [1, 2, 3, 4, 5]  # 배열 선언

      # 요소 접근
      print(arr[0])  # 첫 번째 요소 출력 -> 1

      # 요소 추가 (append)
      arr.append(6)  # 배열 끝에 6 추가
      print(arr)  # [1, 2, 3, 4, 5, 6]

      # 요소 삭제 (remove, pop)
      arr.remove(3)  # 값 3을 삭제
      print(arr)  # [1, 2, 4, 5, 6]

      arr.pop()  # 마지막 요소 삭제
      print(arr)  # [1, 2, 4, 5]

      # 특정 위치에 요소 삽입
      arr.insert(2, 10)  # 인덱스 2 위치에 10 삽입
      print(arr)  # [1, 2, 10, 4, 5]

      # 배열 길이 확인
      print(len(arr))  # 5
    ```
  </TabsContent>
</Tabs>

    ```python
      import array

      # 정수형 배열 생성 ('i'는 정수형을 의미)
      arr = array.array('i', [1, 2, 3, 4, 5])

      # 요소 접근
      print(arr[0])  # 1

      # 요소 추가
      arr.append(6)
      print(arr)  # array('i', [1, 2, 3, 4, 5, 6])

      # 요소 삭제
      arr.remove(3)
      print(arr)  # array('i', [1, 2, 4, 5, 6])

      # 특정 위치에 삽입
      arr.insert(2, 10)
      print(arr)  # array('i', [1, 2, 10, 4, 5, 6])

      # 배열 길이
      print(len(arr))  # 6

    ```
