## 개념
- ✅ `async` 
  - `async`는 **비동기 함수(코루틴, Coroutine)를 정의하는 키워드**
  - `async def`로 정의된 함수는 **반드시 `await`를 사용해야 비동기적으로 실행됨**
    ```python
    async def my_async_function():
        return "비동기 함수 실행"
    ```

- ✅ `await`
  - `await`는 **비동기 함수 내에서만** 사용 가능
  - `await`를 만나면 **해당 작업이 끝날 때까지 기다린 후** 다음 코드 실행
    ```python
    import asyncio

    async def fetch_data():
        print("데이터 가져오는 중...")
        await asyncio.sleep(2)  # 비동기적으로 2초 대기
        print("데이터 가져오기 완료!")

    asyncio.run(fetch_data())

    => 실행결과
    => 데이터 가져오는 중...
    => (2초 대기)
    => 데이터 가져오기 완료!
    ```

## 주의점

1. `await` 없이 `async` 함수 실행 불가
   ```python
   async def example():
    return "Hello"

    result = example()  # ❌ 잘못된 사용법 (Coroutine 객체 반환됨)
    print(result)  # <coroutine object example at 0x...>

    ==== ✅ 해결 방법 =====

    async def example():
        return "Hello"

    result = asyncio.run(example())  # ✅ 이벤트 루프를 통해 실행
    print(result)  # "Hello"
    ````

2. `async` 함수 내에서 동기 코드 사용 시 주의
    ```python
    import time
    import asyncio

    async def blocking_task():
        time.sleep(3)  # ❌ 동기 함수 사용 (비효율적)
        print("완료")

    async def main():
        await blocking_task()

    asyncio.run(main())  # 블로킹이 발생하여 비동기 처리의 의미가 없어짐
    
    ==== ✅ 해결 방법 =====

    import asyncio

    async def non_blocking_task():
        await asyncio.sleep(3)  # ✅ 비동기 대기 사용
        print("완료")

    async def main():
        await non_blocking_task()

    asyncio.run(main())  # 비동기로 실행
    ```
