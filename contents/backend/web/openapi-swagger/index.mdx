## OpenAPI 란?
- **OpenAPI Specification (OAS)**
- RESTful API를 기술하기 위한 표준 포맷(JSON/YAML)
- API의 엔드포인트. 매서드, 파라미터, 응답형식, 인증 방식 등을 정의
- 장점
  - API 자동 문서화
  - 클라이언트 SDK 자동 생성
  - API 테스트 도구와 연동 용이

---
## Swagger/ReDoc
- Swagger UI : 브라우저에서 API 문서를 인터렉티브하게 확인 & 실행할 수 있는 도구
- ReDoc : OpenAPI 스펙을 깔끔한 정적 문서로 렌더링 하는 도구
- FastAPI는 기본적으로 **Swagger UI + ReDoc**를 자동 제공

---

## FastAPI 기본 문서화
- FastAPI 실행 후, 브라우저에서 확인 가능
- Swagger UI → `http://127.0.0.1:8000/docs`
- ReDoc → `http://127.0.0.1:8000/redoc`
- OpenAPI 스펙(JSON) → `http://127.0.0.1:8000/openapi.json`
```python
```python
from fastapi import FastAPI

app = FastAPI(
    title="My API",
    description="FastAPI 예제 서비스",
    version="1.0.0",
)

@app.get("/items/{item_id}", summary="아이템 조회", description="특정 ID의 아이템을 조회합니다.")
def read_item(item_id: int, q: str | None = None):
    return {"item_id": item_id, "q": q}
```

## 주요 기능
1. Summary / Description
   - 각 엔드 포인트에 `summary`, `description` 추가 가능
   - Markdown 지원 -> 예제, 링크, 코드블록 포함 가능
```python
@app.post(
    "/users/",
    summary="사용자 생성",
    description="""
새 사용자를 생성합니다.  
- **name**: 사용자 이름  
- **age**: 나이  
"""
)
def create_user(name: str, age: int):
    return {"name": name, "age": age}
```

2. 응답모델 (Response Model)
   - Swagger 문서에 응답 스키마가 자동으로 표시
```python
from pydantic import BaseModel

class Item(BaseModel):
    id: int
    name: str
    description: str | None = None

@app.get("/items/{item_id}", response_model=Item)
def get_item(item_id: int):
    return {"id": item_id, "name": "Sample", "description": "Test item"}
``` 

3. 상태 코드/응답 설명
```python
from fastapi import status

@app.post("/login", status_code=status.HTTP_201_CREATED, responses={
    400: {"description": "잘못된 요청"},
    401: {"description": "인증 실패"},
})
def login():
    return {"msg": "success"}
```

4. 태그
  - Swagger UI에서 그룹화 되어 가독성 향상
```python
@app.get("/products/", tags=["Products"])
def list_products():
    return []
```

5. 보안 스키마 정의 (JWT/OAuth2)
  - Swggaer UI에 `Authorize` 버튼이 자동으로 생김
  - 토큰 입력 후 API 호출 가능
```python
from fastapi.security import OAuth2PasswordBearer

oauth2_scheme = OAuth2PasswordBearer(tokenUrl="token")

@app.get("/users/me")
def read_users_me(token: str = Depends(oauth2_scheme)):
    return {"token": token}
```

6. 커스터마이징
   - `FastAPI(docs_url="/swagger", redoc_url=None, openapi_url="/openapi.json")` -> 경로 수정 가능
   - OpenAPI 스펙(JSON)을 직접 수정/추가하려면 `app.openapi()` 오버라이드 가능
```python
from fastapi.openapi.utils import get_openapi

def custom_openapi():
    if app.openapi_schema:
        return app.openapi_schema
    openapi_schema = get_openapi(
        title="Custom API",
        version="2.0.0",
        description="내 커스텀 API 문서",
        routes=app.routes,
    )
    openapi_schema["info"]["x-logo"] = {"url": "https://fastapi.tiangolo.com/img/logo-margin/logo-teal.png"}
    app.openapi_schema = openapi_schema
    return app.openapi_schema

app.openapi = custom_openapi
```
