## 목적
- **그래프 탐색**을 넘어, 실전에서 자주 쓰이는 고급 그래프 알고리즘 이해
- 위상 정렬, 최단 경로, 최소 신장 트리, 네트워크 플로우 등 핵심 알고리즘의 원리와 복잡도 이해
- 시간 복잡도외 사용 사례 정리
---
## 개념
- **그래프(Graph)** : 정점(vertex)과 간선(Edge)로 이루어진 자료구조
- **방향 그래프/무방향 그래프**, **가중치 그래프/무가중치 그래프** 등으로 분류
- 고급 알고리즘은 보통 **탐색(DFS/BFS)**을 기반으로 확장
---
## 주요 알고리즘
1. 위상 정렬 (Topological Sort)
   - 개념 : DAG(방향 비순환 그래프)의 정점들을 선행 관계를 만족하는 선형 순서로 나열
   - 알고리즘
     - DFS 기반 : 백트래킹 순서의 역순
     - Kahn 알고리즘 : 진입 차수 0 부터 큐처리
   - 복잡도 : `O(V+E)`  
   - 횔용 : 작업 스케쥴링, 빌드 순서, 의존성 분석
