---
## 핵심정리
- Greedy = 매 단계 국소 최적 선택
- 항상 정답 보장 ❌ : 탐욕적 선택 속성 + 최적 부분 구조 조건 필요
- 대표 사례 : 활동 선택, Kruskal/Prim MST, Huffman Coding
---
## 개념
- **Greedy Algorithm (탐욕 알고리즘)**
  - 매 단계에서 가장 좋아 보이는 선택(국소 최적해)을 하는 방식으로 전체 문제의 해를 구하는 알고리즘
  - Greedy가 항상 최적해를 보장하는 것은 아니며, 문제의 구조적 특성이 필요
- 활용 사례
  - 네트워크 설계 (최소 신장 트리)
  - 데이터 압축 (허프만 코딩)
  - 작업 스케쥴링 (회의실 배정, CPU 작업 스케쥴링)
  - 최단 경로 (단, 다익스트라는 Greedy + Relaxation 혼합)
---
## 조건
✅ 최적해 보장 조건
1. 탐욕적 선택 속성  (Greedy Choice Property)
   - 국소적으로 최선의 선택이 전체적으로도 최적해로 이어짐
2. 최적 부분 구조 (Optimal Substructure)
   - 문제의 최적해가 부분 문제의 최적해로 구성됨
---
## 대표 알고리즘

| 알고리즘 | 설명 | 시간 복잡도 |
|----------|------|-------------|
| **활동 선택 (Activity Selection)** | 회의실 배정 문제: 끝나는 시간이 가장 빠른 활동을 선택 | O(n log n) |
| **Kruskal MST** | 간선 가중치 오름차순 정렬 후 Union-Find로 MST 구성 | O(E log E) |
| **Prim MST** | 임의 시작 정점에서, 가장 짧은 간선을 선택해 확장 | O(E log V) |
| **Huffman Coding** | 빈도 기반 이진 트리 구성, 최적 압축 코드 생성 | O(n log n) |

## 예시
1. 활동 선택 문제
   ```python
   # 종료 시간이 빠른 순서로 정렬 후 선택
   def activity_selection(intervals):
      intervals.sort(key=lambda x: x[1])  # 종료시간 기준
      result = []
      last_end = 0
      for start, end in intervals:
         if start >= last_end:
               result.append((start, end))
               last_end = end
      return result

   # 예시 실행
   intervals = [(1,3),(2,5),(4,6),(6,7),(5,9),(8,9)]
   print(activity_selection(intervals))  
   # 출력: [(1,3), (4,6), (6,7), (8,9)]
   ```
2. Kruskal 최소 신장 트리
   ```python
   class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra != rb:
            self.parent[rb] = ra

   def kruskal(n, edges):
      edges.sort(key=lambda x: x[2])  # 가중치 기준 정렬
      uf = UnionFind(n)
      mst = []
      for u, v, w in edges:
         if uf.find(u) != uf.find(v):
               uf.union(u, v)
               mst.append((u, v, w))
      return mst

   # 예시 실행
   edges = [(0,1,1),(0,2,3),(1,2,2),(1,3,4),(2,3,5)]
   print(kruskal(4, edges))  # [(0,1,1),(1,2,2),(0,2,3)] 같은 MST
   ```
