## List
- **순서가 있는(mutable)** 컬렉션으로, 다양한 타입의 요소들을 포함할 수 있음
- 대괄호(`[]`)를 사용하여 생성
- 인덱스를 사용하여 요소에 접근 및 수정 가능
```python
# 리스트 생성
fruits = ["apple", "banana", "cherry"]

# 요소 접근 및 수정
print(fruits[1])      # 출력: "banana"
fruits[1] = "blueberry"
print(fruits)         # 출력: ["apple", "blueberry", "cherry"]

# 요소 추가
fruits.append("date")
print(fruits)         # 출력: ["apple", "blueberry", "cherry", "date"]
```

## Tuple
- **순서가 있는(immutable)** 컬렉션으로, 한 번 생성되면 수정 불가
- 소괄호(())를 사용하여 생성
- 요소 접근은 리스트와 유사하지만, 수정은 불가능
```python
# 튜플 생성
coordinates = (10, 20, 30)

# 요소 접근
print(coordinates[0])  # 출력: 10

# coordinates[1] = 50  # 오류 발생 (튜플은 변경 불가)
```

## Set
- **순서가 없고, 중복을 허용하지 않는** 컬렉션 (수학에서 집합과 유사)
- 중괄호({})나 set() 함수를 사용하여 생성
- 중복된 요소는 저장되지 않으며, **순서가 없으므로 인덱스 접근은 불가능**
```python
# 세트 생성
numbers = {1, 2, 3, 2, 1}
print(numbers)  # 출력: {1, 2, 3} (중복 제거)

# 요소 추가
numbers.add(4)
print(numbers)  # 출력: {1, 2, 3, 4}

# 요소 제거
numbers.remove(2)
print(numbers)  # 출력: {1, 3, 4}

```

## Dictionary
- **키-값(key-value) 쌍을 저장**하는 매핑 자료형
- 중괄호({})를 사용하여 생성하며, 키는 불변(immutable) 타입이어야 하고, 유일해야함
- 키를 통해 값에 빠르게 접근 가능
```python
# 딕셔너리 생성
person = {
    "name": "Alice",
    "age": 30,
    "city": "New York"
}

# 값 접근
print(person["name"])  # 출력: "Alice"

# 값 수정
person["age"] = 31
print(person)          # 출력: {"name": "Alice", "age": 31, "city": "New York"}

# 키-값 쌍 추가
person["job"] = "Engineer"
print(person)
```
