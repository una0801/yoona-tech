- **소수(prime)** → 1과 자신으로만 나뉘는 수 · 모든 정수의 곱셈 기본 단위
- 핵심 도구 → √n 판정 · 에라토스테네스의 체 · 소인수분해
- 쓰임 → 해시 modulus·암호 키 생성·약수 개수·LCM 계산

## 배수 지우는 체로 보기

- 2부터 n까지 수를 늘어놓고 → 2의 배수, 3의 배수, ... 차례로 **지움(체로 거름)**
- 끝까지 안 지워지고 남은 수 → 소수
- 마치 체로 모래(합성수)를 거르고 알갱이(소수)만 남기는 것

<KeyPoint title="이 비유에서 가져갈 것">
소수 판정 하나는 √n까지 나눠보면 충분 · 여러 소수를 한 번에 구할 땐 배수를 지우는 체가 압도적으로 빠름 ·
체는 "각 소수의 배수만 지운다"로 중복 작업을 줄임
</KeyPoint>

## 단일 소수 판정 — √n까지면 충분

- n = a·b 라면 a와 b 중 하나는 반드시 √n 이하
- 따라서 **2부터 √n까지** 나눠떨어지는 수 없으면 소수
- n까지 다 나누는 O(n)보다 O(√n)으로 단축

```python
def is_prime(n):
    if n < 2:
        return False
    i = 2
    while i * i <= n:              # √n까지 (i*i로 오버플로 회피)
        if n % i == 0:
            return False
        i += 1
    return True
# 시간 O(√n) · 공간 O(1)
```

## 에라토스테네스의 체 — 거르는 과정

- `is_p[i]` 전부 True로 시작 → 2부터 순회하며 소수면 그 배수 전부 False
- 배수 지우기 시작점 → `i*i` (그 전 배수는 더 작은 소수가 이미 지움)

```mermaid
flowchart LR
    A["2~30 전부 후보"] -->|2 배수 제거| B["4,6,8...30 ✗"]
    B -->|3 배수 제거| C["9,15,21,27 ✗"]
    C -->|5 배수 제거| D["25 ✗"]
    D -->|남은 수| E["2 3 5 7 11 13...29 = 소수"]
```

| 단계 | 처리 소수 | 지우는 수(2~30) |
| --- | --- | --- |
| 1 | 2 | 4 6 8 10 ... 30 |
| 2 | 3 | 9 15 21 27 (6,12...은 이미) |
| 3 | 5 | 25 (10,15,20은 이미) |
| 4 | 7 | 49>30 → 종료 |

```python
def sieve(n):                     # n 이하 소수 리스트
    is_p = [True] * (n + 1)
    is_p[0] = is_p[1] = False
    i = 2
    while i * i <= n:             # √n까지만 시작점 검사
        if is_p[i]:
            for j in range(i * i, n + 1, i):   # i*i부터 i 간격 제거
                is_p[j] = False
        i += 1
    return [x for x in range(2, n + 1) if is_p[x]]
# 시간 O(n log log n) · 공간 O(n)
```

## 소인수분해 — 최소 소인수로 쪼개기

- 2부터 √n까지 나눠떨어지면 그 인수로 계속 나눔
- 마지막에 1 아닌 값 남으면 → 그 자체가 소수 인수

```python
def factorize(n):                 # {소인수: 지수}
    factors = {}
    d = 2
    while d * d <= n:
        while n % d == 0:
            factors[d] = factors.get(d, 0) + 1
            n //= d
        d += 1
    if n > 1:                     # 남은 큰 소인수
        factors[n] = factors.get(n, 0) + 1
    return factors
# 시간 O(√n) · 체로 최소소인수(SPF) 전처리 시 O(log n) 분해 가능
```

## 선형 체(Linear Sieve) 개요

- 에라토스테네스는 합성수를 **여러 번** 지움(예: 12를 2·6, 3·4로 중복)
- 선형 체 → 각 합성수를 "최소 소인수 × 인수" 한 번만 지움 → **O(n)**
- 부수 효과 → 각 수의 최소소인수(SPF) 표를 같이 얻어 빠른 소인수분해

<Compare>
<CompareCol title="에라토스테네스" subtitle="구현 단순" color="sky">
- O(n log log n) · 사실상 충분히 빠름
- 합성수 중복 제거 발생
- 일반 코딩테스트 표준
</CompareCol>
<CompareCol title="선형 체" subtitle="중복 제거" color="green">
- O(n) · 각 수 한 번만 처리
- SPF 표 동시 획득
- n이 매우 크거나 대량 분해 시
</CompareCol>
</Compare>

```python
def linear_sieve(n):              # 소수 리스트 + 최소소인수 spf
    spf = [0] * (n + 1)
    primes = []
    for i in range(2, n + 1):
        if spf[i] == 0:           # 아직 안 지워짐 → 소수
            spf[i] = i
            primes.append(i)
        for p in primes:
            if p > spf[i] or i * p > n:
                break
            spf[i * p] = p        # 최소 소인수로 한 번만 표시
    return primes, spf
# 시간 O(n) · 공간 O(n)
```

<Note type="danger" title="복잡도·메모리 함정">
- 체 배열 → n=10^8이면 메모리 폭발 → bytearray·비트셋·구간 체(segmented sieve) 고려
- 배수 제거 시작 `i*2` 대신 `i*i` → 작은 소수가 이미 지운 구간 재처리 회피
- `i*i <= n` 비교 → 큰 언어선 i*i 오버플로 (파이썬은 안전)
- 단일 판정에 체를 쓰면 과함 → 한 번만 검사면 √n 판정으로 충분
</Note>
