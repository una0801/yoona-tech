## 목적
- 정렬의 개념과 필요성 이해
- 주요 정렬 알고리즘의 시간/공간 복잡도 비교
- 상황별로 어떤 정렬을 선택해야 하는지의 기준
---
## 핵심정리
- 정렬은 크게 비교 기반과 비비교 기반으로 나눔
- 평균적으로 가장 많이 쓰이는 정렬 : 퀵, 머지, 힙
- 범위 제한된 정수 데이터 ➡️ 계수/기수
---
## 개념
- **Sorting(정렬)** : 데이터 원소들을 일정한 기준(오름차순/내림차순 등)에 따라 순서대로 재배치하는 과정
- 정렬은 검색, 탐색, 데이터 분석의 전처리 단계로 활용 빈도가 매우 높다
---
## 분류
1. **비교 기반 정렬(Comparision Sort)**
   - 두 원소를 비교하여 순서를 결정
   - ex: 버블, 삽입, 선택, 퀵, 머지, 힙
2. **비비교 기반 정렬(Non-Comparision Sort)**
   - 원소의 구조적 특성을 이용
   - ex: 계수 정렬(Counting), 기수 정렬(Radix), 버킷 정렬(Bucket)
---
## 대표 알고리즘과 복잡도

| 알고리즘 | 평균 시간 | 최악 시간 | 공간 | 특징 |
|----------|-----------|-----------|------|------|
| 버블 정렬 (Bubble) | O(n²) | O(n²) | O(1) | 구현 단순, 비효율 |
| 선택 정렬 (Selection) | O(n²) | O(n²) | O(1) | 교환 횟수 최소 |
| 삽입 정렬 (Insertion) | O(n²) | O(n²) | O(1) | 거의 정렬된 데이터에 효율적 |
| 머지 정렬 (Merge) | O(n log n) | O(n log n) | O(n) | 안정 정렬, 분할정복 |
| 퀵 정렬 (Quick) | O(n log n) | O(n²) | O(log n) | 평균적으로 가장 빠름 |
| 힙 정렬 (Heap) | O(n log n) | O(n log n) | O(1) | 힙 자료구조 이용 |
| 계수 정렬 (Counting) | O(n+k) | O(n+k) | O(k) | 정수 범위 제한 시 효율적 |
| 기수 정렬 (Radix) | O(nk) | O(nk) | O(n+k) | 자릿수 기준 정렬 |
| 버킷 정렬 (Bucket) | O(n+k) | O(n²) | O(n+k) | 균등 분포 데이터에 효율 |

## 예시
1. 삽입 정렬
   ```python
   def insertion_sort(arr):
    for i in range(1, len(arr)):
        key = arr[i]
        j = i - 1
        while j >= 0 and arr[j] > key:
            arr[j+1] = arr[j]
            j -= 1
        arr[j+1] = key
    return arr
   ```
2. 퀵 정렬
   - 사례 : 일반적인 정렬에서 가장 빠름
   ```python
   def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr)//2]
    left = [x for x in arr if x < pivot]
    mid = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quick_sort(left) + mid + quick_sort(right)
   ```
3. 머지 정렬
   - 사례 : 안정성 필요(ex. DB 레코드 정렬)
   ```python
   def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr)//2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    return merge(left, right)

    def merge(left, right):
        res = []
        i = j = 0
        while i < len(left) and j < len(right):
            if left[i] <= right[j]:
                res.append(left[i]); i += 1
            else:
                res.append(right[j]); j += 1
        res.extend(left[i:]); res.extend(right[j:])
        return res
   ```
4. 계수 정렬
   - 사례 : 데이터가 정수이고 범위가 제한적일 때
   ```python
   def counting_sort(arr):
    k = max(arr)
    count = [0] * (k+1)
    for num in arr:
        count[num] += 1
    res = []
    for i in range(len(count)):
        res.extend([i]*count[i])
    return res
   ```
