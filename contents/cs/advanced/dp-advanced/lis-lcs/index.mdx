- LIS → 한 수열에서 점점 커지는 가장 긴 줄
- LCS → 두 수열의 공통 흐름 중 가장 긴 것
- 둘 다 "부분수열"(연속 아님) · 표를 채워 길이와 경로를 동시 추적

## 점점 키 커지는 줄 세우기 · 두 문서 공통부분 찾기

- **LIS** → 키 순서 흐트러진 사람들 중 "점점 키 커지는" 가장 긴 줄 뽑기
- **LCS** → 두 문서를 나란히 놓고 순서 유지하며 겹치는 가장 긴 흐름 찾기
- 실무 → LIS: 버전 호환·주가 추세 / LCS: `diff`·git 변경 비교·DNA 정렬

<KeyPoint title="비유에서 가져갈 것">
LIS = "지금까지 길이 k 줄의 최소 끝값" 을 관리하면 이분 탐색으로 O(n log n) ·
LCS = "두 끝 글자 같으면 대각선+1, 다르면 위·왼쪽 max" 표 채우기
</KeyPoint>

## LIS — O(n²) 기본 DP

- `dp[i]` → i 로 끝나는 LIS 길이 · 앞쪽에서 더 작은 값 찾아 +1
- 수열 `[10, 20, 10, 30, 20, 50]` 예시

| i | 0 | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- | --- |
| 값 | 10 | 20 | 10 | 30 | 20 | 50 |
| dp | 1 | 2 | 1 | 3 | 2 | **4** |

- `dp[3]=3` → 10,20,30 / `dp[5]=4` → 10,20,30,50
- 답 → `max(dp)` = 4

```python
def lis_n2(nums):
    n = len(nums)
    dp = [1] * n
    for i in range(n):
        for j in range(i):
            if nums[j] < nums[i]:
                dp[i] = max(dp[i], dp[j] + 1)
    return max(dp) if dp else 0
# 시간 O(N²) · 공간 O(N)
```

## LIS — O(n log n) 이분 탐색

- `tails[k]` → 길이 k+1 증가수열의 **가능한 최소 끝값**
- 새 값 x → `tails` 에서 x 들어갈 위치를 이분 탐색 → 교체 또는 확장
- `tails` 길이 = LIS 길이 (단 `tails` 내용 자체가 실제 LIS는 아님)

<Timeline>
<TimelineItem title="x가 tails 끝값보다 큼">
tails 뒤에 append → 더 긴 증가수열 발견
</TimelineItem>
<TimelineItem title="x가 중간에 들어감">
bisect_left 위치 값 교체 → 같은 길이 더 작은 끝값 → 확장 여지 ↑
</TimelineItem>
<TimelineItem title="모든 원소 처리 후">
len(tails) → LIS 길이 · 경로 복원은 별도 인덱스 추적 필요
</TimelineItem>
</Timeline>

```python
import bisect

def lis_nlogn(nums):
    tails = []                      # tails[k] = 길이 k+1 수열 최소 끝값
    for x in nums:
        i = bisect.bisect_left(tails, x)   # 엄격 증가 → left
        if i == len(tails):
            tails.append(x)
        else:
            tails[i] = x
    return len(tails)
# 시간 O(N log N) · 공간 O(N)
```

<Note type="warning" title="증가 vs 비감소">
- 엄격 증가(strictly) → `bisect_left`
- 같은 값 허용(non-decreasing) → `bisect_right`
- 부등호 조건 헷갈리면 둘 다 손으로 작은 케이스 검증
</Note>

## LCS — 2차원 DP와 역추적

- `dp[i][j]` → a 앞 i글자, b 앞 j글자의 LCS 길이
- 점화식 → 끝 글자 같으면 `dp[i-1][j-1]+1` · 다르면 `max(dp[i-1][j], dp[i][j-1])`
- `ACAYKP` vs `CAPCAK` (간단화는 `ABCB` × `BDCAB`)

| `ABCB` \ `BDCAB` | "" | B | D | C | A | B |
| --- | --- | --- | --- | --- | --- | --- |
| "" | 0 | 0 | 0 | 0 | 0 | 0 |
| A | 0 | 0 | 0 | 0 | 1 | 1 |
| B | 0 | 1 | 1 | 1 | 1 | 2 |
| C | 0 | 1 | 1 | 2 | 2 | 2 |
| B | 0 | 1 | 1 | 2 | 2 | **3** |

- 최댓값 우하단 **3** → 공통수열 `BCB`
- 역추적 → 우하단에서 출발 · 같으면 대각선 이동(글자 채택) · 다르면 큰 쪽으로

```python
def lcs(a, b):
    n, m = len(a), len(b)
    dp = [[0] * (m + 1) for _ in range(n + 1)]
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            if a[i-1] == b[j-1]:
                dp[i][j] = dp[i-1][j-1] + 1
            else:
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])
    return dp[n][m]
# 시간 O(N·M) · 공간 O(N·M)

def lcs_string(a, b):              # 실제 수열 복원
    n, m = len(a), len(b)
    dp = [[0] * (m + 1) for _ in range(n + 1)]
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            dp[i][j] = (dp[i-1][j-1] + 1 if a[i-1] == b[j-1]
                        else max(dp[i-1][j], dp[i][j-1]))
    res, i, j = [], n, m
    while i > 0 and j > 0:         # 우하단 → 좌상단 역추적
        if a[i-1] == b[j-1]:
            res.append(a[i-1]); i -= 1; j -= 1
        elif dp[i-1][j] >= dp[i][j-1]:
            i -= 1
        else:
            j -= 1
    return ''.join(reversed(res))
```

## 편집 거리 — LCS의 사촌

- 한 문자열을 다른 문자열로 바꾸는 최소 연산(삽입·삭제·교체)
- `dp[i][j]` → a 앞 i, b 앞 j 변환 비용 · 같으면 대각선 그대로, 다르면 세 연산 min+1

```python
def edit_distance(a, b):
    n, m = len(a), len(b)
    dp = [[0] * (m + 1) for _ in range(n + 1)]
    for i in range(n + 1): dp[i][0] = i      # 전부 삭제
    for j in range(m + 1): dp[0][j] = j      # 전부 삽입
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            if a[i-1] == b[j-1]:
                dp[i][j] = dp[i-1][j-1]
            else:
                dp[i][j] = 1 + min(dp[i-1][j],     # 삭제
                                   dp[i][j-1],     # 삽입
                                   dp[i-1][j-1])   # 교체
    return dp[n][m]
# 시간 O(N·M) · 공간 O(N·M) → 두 행만 유지 시 O(M)
```

- LIS → O(N²) 는 경로·dp값 직관적 · O(N log N) 은 빠르나 경로 복원 추가 작업
- LCS → 길이만 필요하면 두 행만 유지 O(min(N,M)) 공간 · 역추적 필요하면 전체 표 유지
- LCS 의 LIS 변환 → 한 쪽이 순열이고 중복 없으면 위치 매핑 후 LIS 로 O(N log N) 가속
- 편집 거리 → 가중치 다른 연산이면 min 안에 비용 상수만 조정
</Note>
