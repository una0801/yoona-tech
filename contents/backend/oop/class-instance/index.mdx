## 핵심 요약

| 개념 | 무엇인가? | 누가 만들까? | 예시 |
|------|-----------|--------------|-------|
| **Instance (객체)** | 실제로 존재하는 개별 객체 | **클래스(class)** | `dog = Dog()` |
| **Class (클래스)** | 인스턴스를 만드는 설계도 | **메타클래스(metaclass)** | `class Dog:` |
| **Metaclass (메타클래스)** | 클래스를 만드는 설계도 | (거의 항상) **type** | `type(Dog)` |

---
## 관계
```
type ─────▶ class Dog ─────▶ dog = Dog()
(metaclass) (class) (instance)
```
- 인스턴스는 **클래스로부터 만들어짐**
- 클래스는 **메타클래스(type)** 로 만들어짐
---
## Class
- **객체를 생성하기 위한 틀**
- 예시 : `Dog` -> "Dog"라는 타입의 설계도
- 이 설계도로 실제 객체를 만들어냄 (python에서 클래스는 메모리에 존재하는 하나의 객체)
```python
class Dog:
    species = "Canis" # 클래스 속성
    def bark(self):   # 메서드
        print("멍!")

# 코드가 실행 될 때 Dog라는 새로운 "클래스 객체" 생성
```
---
## instance
- 클래스로부터 생성된 실제 객체
- 특징 :
    - 개별 상태(state)를 가짐
    - 서로 다른 인스턴스는 서로 다른 데이터를 가짐
    - 클래스에서 정의된 메서드를 사용할 수 있음
```python
dog1 = Dog()  # dog는 Dog의 인스턴스
dog2 = Dog()



dog.name = "Coco"
dog2 = Dog()
dog2.name = "Bori" # coco 와 Bori는 각 인스턴스의 독립적인 속성
```
---
## class vs instance
- 파이썬의 속성 탐색 시 순서 : `인스턴스 → 클래스 → 부모 클래스 → ...`
- 인스턴스 속성
    - 인스턴스에 직접 부여한 속성
    - 인스턴스마다 다름
    - `dog.__dict__` 안에만 존재
```python
class Dog:
    def __init__(self, name):
        self.name = name  # 인스턴스마다 다름
```
- 클래스 속성 
    - 클래스 정의 안에 직접 적힌 속성
    - 모든 인스턴스가 공유
    - `Dog.__dict__ ` 안에 저장
```python
class Dog:
    species = "Canis"  # 모든 인스턴스가 공유
```

## 클래스가 객체라는 의미
- python 에서 `Dog`는 단순한 코드블록이 아니라 실제로 메모리에 존재하는 하나의 객체
    - `Dog`라는 클래스 객체는 `type` 이라는 메타클래스의 인스턴스
    - 이 뜻은 python이 클래스 정의 시점을 제어하거나 클래스를 동적으로 생성할 수 있게하는 원리
```python
print(type(Dog))  
# <class 'type'>
```
(1) 클래스 속성에 접근할 수 있는 이유
    - 클래스는 객체이므로 `var(Dogs)` 를 통해 내부 dict 조회 가능
(2) Django의 class Meta 패턴
    - `Meta` 클래스는 클래스 속성으로 들어간 또 하나의 객체이기 때문에 동작
    ```python
    class User:
    class Meta:
        db_table = "user"
    ```
(3) SQLAlchemy Declarative Base
    - `Column()` 들이 클래스 속성으로 정의되면 메타클래스가 이를 자동으로 수집하여 테이블 정보를 구성
    - **클래스 정의 = 규칙을 선언하는 영역** 이며, 메타클래스가 이를 처리
---
## 요약
- 클래스는 **객체를 만들기 위한 틀** 이면서, **그 자체로 객체**
- 인스턴스는 클래스에서 생성되는 **실제 개별 객체**
- 클래스 속성은 클래스 자체에 저장되며, 모든 인스턴스가 공유
- 인스턴스 속성은 각 객체마다 독립적으로 존재
- Python OOP구조를 이해하면 "클래스 정의 기반 규칙 처리" 패턴을 자연스럽게 이해 가능
