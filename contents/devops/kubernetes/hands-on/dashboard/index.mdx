## 대시보드란?
 - kubernetes 리소스들을 웹에서 관리, 모니터링 할 수 있도록 도와주는 웹 기반 UI
 - 운영환경에서는 보안상 위험할 수 있으므로 RBAC 설정과 인증 토큰 제한, Ingress 인증, VPN 접속 등 보안 고려 필수
---
## 주요 기능
| 기능             | 설명                                        |
| -------------- | ----------------------------------------- |
| 🖥️ 클러스터 상태 보기 | 노드, 네임스페이스, 파드 상태를 한눈에 확인                 |
| 📦 리소스 생성/삭제   | 웹에서 Deployment, Service 등 직접 생성           |
| 📊 리소스 사용량 보기  | Pod의 CPU/Memory 사용량 (Metrics Server 연동 시) |
| 🐛 이벤트 확인      | 에러/이벤트 로그 확인 (예: CrashLoopBackOff 등)      |
| 🔧 YAML 편집     | 웹 상에서 리소스를 수정하거나 삭제 가능                    |
| 👥 사용자 권한 관리   | RBAC 기반 접근 제한 (Admin/ReadOnly 등 설정 가능)    |

## 설치 과정
<Stepper>
  <StepperItem title="1: Dashboard 설치">
  ```bash
  kubectl apply -f https://raw.githubusercontent.com/kubernetes/dashboard/v2.7.0/aio/deploy/recommended.yaml
 
  ✔️ 이 명령은 다음 리소스를 자동으로 설치:
   - kubernetes-dashboard (Deployment + Service)
   - 관련 RBAC, Namespace, Secret 등
  ```
  </StepperItem>
  <StepperItem title="2: 설치 확인">
    ```bash
   kubectl get pods -n kubernetes-dashboard
    
   # 출력 예시 
   [root@master-node ~]# kubectl get pods -n kubernetes-dashboard
   NAME                                         READY   STATUS    RESTARTS   AGE
   dashboard-metrics-scraper-5657497c4c-66phb   1/1     Running   0          2m50s
   kubernetes-dashboard-78f87ddfc-c99kz         1/1     Running   0          2m50s
    ```
  </StepperItem>
  <StepperItem title="3: Service 노출 (NodePort 방식)">
```bash
# 📍 dashboard 기본 설치는 ClusterIP로 되어있어서 외부에서 접속 불가
    -> NodePort로 수정해야 웹 브라우저에서 접근 가능

✅ 방법 1 : 기존 서비스 수정
kubectl -n kubernetes-dashboard edit svc kubernetes-dashboard

# spec 부분에서 type을 변경
type: ClusterIP   →   type: NodePort

✅ 방법 2 : 새 서비스 따로 만들기
kubectl -n kubernetes-dashboard expose deployment kubernetes-dashboard \
  --type=NodePort --name=kubernetes-dashboard-external

✔️ 노출 포트 확인
[root@master-node ~]# kubectl get svc -n kubernetes-dashboard
NAME                        TYPE        CLUSTER-IP       EXTERNAL-IP   PORT(S)         AGE
dashboard-metrics-scraper   ClusterIP   10.111.109.130   <none>        8000/TCP        7m45s
kubernetes-dashboard        NodePort    10.98.211.73     <none>        443:32278/TCP   7m45s
```
</StepperItem>
<StepperItem title="4: 웹 브라우저 접속">
-  주소 형식: https://&lt;노드 IP&gt;:&lt;NodePort&gt;

- 예시: https://192.168.140.19:32278
- 보안 경고(HTTPS 인증서 없음)는 무시하고 진행
</StepperItem>

<StepperItem title="5: 로그인 인증 설정">
▶️ 방법 1: admin user + token 로그인 (가장 쉬움)
Admin 권한 생성용 YAML 만들기
```bash
cat <<EOF | kubectl apply -f -
apiVersion: v1
kind: ServiceAccount
metadata:
  name: admin-user
  namespace: kubernetes-dashboard
---
apiVersion: rbac.authorization.k8s.io/v1
kind: ClusterRoleBinding
metadata:
  name: admin-user-binding
roleRef:
  apiGroup: rbac.authorization.k8s.io
  kind: ClusterRole
  name: cluster-admin
subjects:
- kind: ServiceAccount
  name: admin-user
  namespace: kubernetes-dashboard
EOF

# 토큰 가져오기

kubectl -n kubernetes-dashboard create token admin-user
→ 나오는 긴 문자열이 로그인 토큰
```
