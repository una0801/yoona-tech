# Embedding Fine-tuning

Sentence-Transformers를 활용한 임베딩 모델 파인튜닝 방법을 알아봅니다.

## 기본 개념

### Sentence-Transformers
- 문장 수준의 임베딩을 위한 프레임워크
- BERT, RoBERTa 등 다양한 모델 지원

## 파인튜닝 과정

1. 데이터 준비
2. 모델 설정
3. 학습 실행
4. 평가 및 최적화

더 자세한 내용은 추후 업데이트 예정입니다.
