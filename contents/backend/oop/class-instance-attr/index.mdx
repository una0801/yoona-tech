## 핵심 요약

| 구분 | 저장 위치 | 공유 여부 | 탐색 우선순위 | 예시 |
|------|-----------|-----------|----------------|------|
| **Class Attribute** | `Class.__dict__` | 인스턴스끼리 **공유** | 인스턴스에 없을 경우 사용 | `Dog.species` |
| **Instance Attribute** | `obj.__dict__` | **각 인스턴스마다 독립적** | 항상 최우선 | `dog.name = "Coco"` |

- 인스턴스에서 속성을 조회할 때 파이썬에서는 아래와 같은 순서로 탐색
    - **인스턴스 ➡️ 클래스 ➡️ 부모 클래스 (MRO)**
- 인스턴스에 동일 이름의 속성을 정의하면 **클래스 속성을 가림(override)**
---
## Class Attribute
- 클래스 정의 안에서 바로 선언한 변수는 **클래스 속성**
```python
class Dog:
    species = "Canis"   # 클래스 속성
```
- 특징
    - 모든 인스턴스가 공유
    - 값은 `Dog.__dict__` 안에 보관
    - 메로리를 아끼고 싶을 때 많이 사용 (ex. 공통 설정값)
```python
d1 = Dog()
d2 = Dog()

print(d1.species, d2.species)
# Canis Canis
```
---
## Instance Attribute
- 인스턴스마다 각각 따로 저장되는 값
```python
class Dog:
    def __init__(self, name):
        self.name = name   # 인스턴스 속성
```
- 특징
    - 각 객체마다 독립적
    - 실제 값은 `dog.__dict__` 라는 인스턴스의 개인 저장공간에 보관
```python
d1 = Dog("Coco")
d2 = Dog("Bori")

print(d1.name)  # Coco
print(d2.name)  # Bori
```
---
## 속성 탐색 순서
- Python은 속성을 찾을 때 아래 순서로 검색
```
obj.__dict__       ➜   인스턴스 속성
Class.__dict__     ➜   클래스 속성
부모 클래스(MRO)      ➜   상속 체인에 따라 탐색
```
```python
class A:
    x = 10   # 클래스 속성

a = A()
a.y = 20    # 인스턴스 속성

print(a.y)  # 1) 인스턴스에서 찾음 → 20
print(a.x)  # 1) 인스턴스에 없음 → 2) 클래스에서 찾음 → 10
```
- **중요** : `a.x` 는 a(인스턴스)에 저장되지 않았는데도 조회 가능
(클래스 속성은 인스턴스가 자동 위임하는 영역이기 때문)
---
## override
- 인스턴스가 클래스 속성을 **가리는** 경우
```python
class A:
    x = 10

a = A()
print(a.x)   # 10

a.x = 99     # 인스턴스 속성 생성 → 클래스 속성을 가림
print(a.x)   # 99

print(A.x)   # 10 (클래스는 그대로)
```
- 속성 탐색 순서로 인해 인스턴스에 x 가 생기면 클래스 x는 무시
```
인스턴스 → 클래스
```
---
## 저장 위치
- `__dict__`
```python
class A:
    x = 10

a = A()
a.y = 20

print(A.__dict__)  # {'x': 10, ...}
print(a.__dict__)  # {'y': 20}
```
- 인스턴스에는 y 만 있고 x는 없음 ➡️ 그러나 `a.x`는 조회 가능(클래스)
---
## 구조 사용 이유
1. 메모리 절약
    - 1000개의 객체가 동일한 값을 들고 있을 필요 없음 (클래스 속성에 올려둠)
2. 구조적 의미 전달
    - 클래스 속성 : 모든 객체가 공유해야하는 값
    - 인스턴스 속성 : 각 객체마다 달라야하는 값
3. 상속/MRO를 통한 확장성
    - 클래스 속성을 기반으로 기본 기능 
    - 인스턴스 속성으로 사용자 정의 동작
