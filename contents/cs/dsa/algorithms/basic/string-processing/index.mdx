## 개념
- 특정 패턴을 찾거나 변환, 분리, 조합 등을 처리
- 문자열은 컴퓨터 프로그래밍에서 매우 중요한 데이터 타입
- 텍스트 검색, 데이터 분석, 정보 검증 ,네트워크 통신 등 다양한 분야에서 문자열 처리 알고리즘이 활용

## Brute Force
- 목적 : 가장 기본적인 문자열 검색 방법으로, 텍스트의 가능한 모든 위치에서 패턴 비교
- 원리 : 텍스트 내에서 패턴이 시작될 수 있는 모든 인덱스에 대해 패턴과 일치하는지 하나하나 확인 (큰 데이터에서 비효율적)
- 시간복잡도 : 최악의 경우 `O(n * m)` (n: 텍스트 길이, m: 패턴 길이)
```python
def naive_search(text, pattern):
    n = len(text)
    m = len(pattern)
    results = []
    for i in range(n - m + 1):
        # 현재 인덱스부터 패턴 길이만큼 문자열 추출 후 비교
        if text[i:i+m] == pattern:
            results.append(i)
    return results

# 사용 예제
text = "ABABDABACDABABCABAB"
pattern = "ABABCABAB"
print("패턴이 발견된 인덱스:", naive_search(text, pattern))
```
## KMP
- Knuth-Morris-Pratt
- 목적 : 문자열 내에서 **특정 패턴**을 효율적으로 **검색**
- 원리 : 패턴 내부의 부분 일치(prefix function) 정보를 미리 계산하여 매칭 실패 시 불필요한 비교를 줄임
- 시간 복잡도: `O(n + m)`
```python
def compute_lps(pattern):
    """
    부분 일치 테이블(LPS: Longest Prefix Suffix) 계산
    """
    lps = [0] * len(pattern)
    length = 0  # 가장 긴 접두사의 길이
    i = 1
    while i < len(pattern):
        if pattern[i] == pattern[length]:
            length += 1
            lps[i] = length
            i += 1
        else:
            if length != 0:
                length = lps[length - 1]
            else:
                lps[i] = 0
                i += 1
    return lps

def kmp_search(text, pattern):
    """
    KMP 알고리즘을 사용한 문자열 패턴 검색
    """
    lps = compute_lps(pattern)
    i = j = 0  # i: text index, j: pattern index
    results = []
    while i < len(text):
        if pattern[j] == text[i]:
            i += 1
            j += 1

        if j == len(pattern):
            results.append(i - j)  # 패턴 발견 위치
            j = lps[j - 1]
        elif i < len(text) and pattern[j] != text[i]:
            if j != 0:
                j = lps[j - 1]
            else:
                i += 1
    return results

# 사용 예제
text = "ABABDABACDABABCABAB"
pattern = "ABABCABAB"
print("패턴이 발견된 인덱스:", kmp_search(text, pattern))
```

## Rabin-Karp
- 목적 : **해시 함수**를 이용하여 텍스트 내에서 빠르게 패턴 검색
- 원리 : 텍스트의 각 부분 문자열에 대해 해시값을 계산하고, 패턴의 해시값과 비교
- 시간복잡도 : 해시 충돌이 발생하면 최악의 경우 `O(nm)`
```python
def rabin_karp(text, pattern, d=256, q=101):
    """
    Rabin-Karp 알고리즘을 사용한 문자열 패턴 검색
    d: 입력 문자 집합의 크기, q: 소수 (해시 모듈러 연산용)
    """
    n = len(text)
    m = len(pattern)
    h = pow(d, m-1) % q  # d^(m-1) mod q
    p = 0  # 패턴의 해시 값
    t = 0  # 텍스트의 해시 값
    results = []

    # 초기 해시 값 계산
    for i in range(m):
        p = (d * p + ord(pattern[i])) % q
        t = (d * t + ord(text[i])) % q

    # 텍스트에서 패턴 검색
    for s in range(n - m + 1):
        if p == t:
            if text[s:s+m] == pattern:
                results.append(s)
        if s < n - m:
            t = (t - ord(text[s]) * h) * d + ord(text[s + m])
            t %= q
    return results

# 사용 예제
text = "GEEKS FOR GEEKS"
pattern = "GEEK"
print("패턴이 발견된 인덱스:", rabin_karp(text, pattern))
```

## Boyer-Moore
- 목적 : 역방향 패턴 매칭을 통해 불필요한 비교를 줄여 문자열 검색의 효율을 극대화
- 원리
  - Bad Character Rule : 패턴과 일치하지 않는 문자가 등장할 경우, 해당 문자에 기반해 패턴을 적절히 이동
  - Good Suffix Rule : 패턴 내에서 일치한 부분 문자열(접미사)을 기준으로 패턴 이동 거리를 결정

## Trie
- 목적 : 문자열 집합을 저장하고. 빠른검색, 삽입, 삭제 연산을 가능하게 하는 자료구조
- 원리 : 각 노드가 문자열의 한 문자를 나타내며, 문자열의 접두사를 공유하는 경우 동일한 경로를 따라 저장
```python
class TrieNode:
    def __init__(self):
        self.children = {}
        self.is_end = False  # 단어의 끝을 표시

class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word):
        node = self.root
        for char in word:
            if char not in node.children:
                node.children[char] = TrieNode()
            node = node.children[char]
        node.is_end = True

    def search(self, word):
        node = self.root
        for char in word:
            if char not in node.children:
                return False
            node = node.children[char]
        return node.is_end

# 사용 예제
trie = Trie()
words = ["apple", "app", "application"]
for word in words:
    trie.insert(word)

print("app 검색:", trie.search("app"))
print("appl 검색:", trie.search("appl"))
```

## Suffix Tree, Suffix Array
- 목적 : 문자열의 모든 접미사를 효율적으로 저장하여 다양한 문자열 문제(패턴 검색, 가장 긴 공통 부분 문자열 등) 해결
- 원리
  - Suffix Tree : 문자열의 모든 접미사를 트리 구조로 저장하며, 패턴 검색, 문자열 비교 등에 매우 효과적
  - Suffix Array : 모든 접미사를 사전 순으로 정렬한 배열로, 메모리 사용이 적고 특정 문제 해결에 효율적
- 특징 
  - Suffix Tree : 빠른 검색 속도를 제공하지만, 메모리 사용량이 많을 수 있음
  - Suffix Array : 메모리 효율성이 뒤어나며, 여러 최적화 기법과 결합하여 사용
