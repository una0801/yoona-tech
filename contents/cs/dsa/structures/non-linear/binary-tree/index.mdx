## 기능

| Prop        | Description                                      |
|-------------|--------------------------------------------------|
| `Root Node` | 트리의 최상단 노드 |
| `Parent Node` | 다른 노드를 포함하는 노드 |
| `Child Node` | 부모 노드 아래에 연결된 노드 |
| `Leaf Node` | 자식 노드가 없는 노드 |
| `Height` | 루트에서 가장 깊은 리프까지의 거리 |
| `Depth` |  루트에서 특정 노드까지의 거리 |

  ☑️ 장점
  - 빠른 탐색 및 정렬 가능 (`O(log n)`, 특정 트리 구조에 따라 다름)
  - 공간 효율적 데이터 저장 가능 (힙, 허프만 트리 등)
  - 탐색, 삽입, 삭제가 빠름 (적절한 균형을 유지하면 `O(log n)`)
  - 다양한 응용 가능 (파일 시스템, 압축, AI 탐색 알고리즘 등)

  ☑️ 단점 
  - 트리 균형이 맞지 않으면 성능 저하 (최악의 경우 `O(n)`)
  - 연결 리스트보다 구현이 복잡함
  - 포인터를 사용하기 때문에 메모리 사용량 증가

## 사용
 - 다양한 트리 기반 데이터 구조의 기초
 - 디렉토리 구조 표현 등

    ```python
    class Node:
        """이진 트리 노드 정의"""
        def __init__(self, value):
            self.value = value
            self.left = None
            self.right = None

    class BinaryTree:
        """이진 트리 구현"""
        def __init__(self):
            self.root = None  # 루트 노드 초기화

        def insert(self, value):
            """이진 트리에 값을 삽입 (왼쪽부터 채우는 방식)"""
            if self.root is None:
                self.root = Node(value)
                return
            
            queue = [self.root]
            while queue:
                node = queue.pop(0)
                if not node.left:
                    node.left = Node(value)
                    return
                else:
                    queue.append(node.left)
                
                if not node.right:
                    node.right = Node(value)
                    return
                else:
                    queue.append(node.right)

        def inorder_traversal(self, node):
            """중위 순회 (Left -> Root -> Right)"""
            if node:
                self.inorder_traversal(node.left)
                print(node.value, end=" ")
                self.inorder_traversal(node.right)

        def preorder_traversal(self, node):
            """전위 순회 (Root -> Left -> Right)"""
            if node:
                print(node.value, end=" ")
                self.preorder_traversal(node.left)
                self.preorder_traversal(node.right)

        def postorder_traversal(self, node):
            """후위 순회 (Left -> Right -> Root)"""
            if node:
                self.postorder_traversal(node.left)
                self.postorder_traversal(node.right)
                print(node.value, end=" ")

        def level_order_traversal(self):
            """레벨 순서 순회 (BFS 방식)"""
            if not self.root:
                return
            
            queue = [self.root]
            while queue:
                node = queue.pop(0)
                print(node.value, end=" ")
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)

    # 이진 트리 생성 및 값 삽입
    bt = BinaryTree()
    bt.insert(1)
    bt.insert(2)
    bt.insert(3)
    bt.insert(4)
    bt.insert(5)

    # 트리 출력
    print("중위 순회 (Inorder): ", end="")
    bt.inorder_traversal(bt.root)  # 4 2 5 1 3
    print("\n전위 순회 (Preorder): ", end="")
    bt.preorder_traversal(bt.root)  # 1 2 4 5 3
    print("\n후위 순회 (Postorder): ", end="")
    bt.postorder_traversal(bt.root)  # 4 5 2 3 1
    print("\n레벨 순서 순회 (Level Order): ", end="")
    bt.level_order_traversal()  # 1 2 3 4 5
    ```
