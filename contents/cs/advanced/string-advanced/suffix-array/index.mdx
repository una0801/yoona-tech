- **접미사 배열(Suffix Array)** → 한 문자열의 모든 접미사를 사전순 정렬한 인덱스 배열
- **LCP 배열** → 정렬된 인접 접미사끼리 공통 접두사 길이 → 중복 구조 파악
- 핵심 → 정적 텍스트를 한 번 정렬해두면 부분 문자열 검색을 O(M log N)으로 반복

## 책 끝 색인 정렬 비유

- 책 모든 단어 위치를 가나다순 색인으로 만들면 → 어떤 단어든 빠르게 찾음
- 접미사 배열 → "문자열의 모든 꼬리"를 사전순 색인으로 정렬해 둔 것
- 패턴 검색 → 정렬된 색인에서 이분 탐색 → 접두사가 패턴인 구간 찾기

<KeyPoint title="이 비유에서 가져갈 것">
접미사 배열 = "모든 접미사를 미리 사전순 정렬한 색인" ·
한 번 만들면 같은 텍스트에 대한 검색을 이분 탐색으로 무한 반복 → 정적 텍스트에 최적
</KeyPoint>

## 접미사 배열 만들기 (`banana`)

- 인덱스별 접미사 나열 → 사전순 정렬 → 시작 인덱스만 배열로 저장

| 정렬순 | 시작 idx | 접미사 |
| --- | --- | --- |
| 0 | 5 | a |
| 1 | 3 | ana |
| 2 | 1 | anana |
| 3 | 0 | banana |
| 4 | 4 | na |
| 5 | 2 | nana |

- 접미사 배열 → `SA = [5, 3, 1, 0, 4, 2]`
- 단순 정렬 → 접미사 길이까지 비교 → O(N² log N) · 개선 알고리즘 O(N log N)·O(N)

## LCP 배열 (인접 접미사 공통 접두사)

- `lcp[i]` → `SA[i-1]`과 `SA[i]` 접미사의 공통 접두사 길이

| i | SA[i] | 접미사 | 이전과 LCP |
| --- | --- | --- | --- |
| 0 | 5 | a | — |
| 1 | 3 | ana | 1 (`a`) |
| 2 | 1 | anana | 3 (`ana`) |
| 3 | 0 | banana | 0 |
| 4 | 4 | na | 0 |
| 5 | 2 | nana | 2 (`na`) |

- LCP → `[-, 1, 3, 0, 0, 2]` · 중복 부분문자열·반복 구조 분석에 핵심
- Kasai 알고리즘 → SA로부터 LCP를 O(N)에 계산

## Python 구현

```python
def build_suffix_array(s: str) -> list[int]:
    n = len(s)
    sa = list(range(n))
    rank = [ord(c) for c in s]
    tmp = [0] * n
    k = 1
    while k < n:                         # 2배씩 늘려가며 정렬 (O(N log^2 N))
        sa.sort(key=lambda i: (rank[i], rank[i + k] if i + k < n else -1))
        tmp[sa[0]] = 0
        for i in range(1, n):
            prev, cur = sa[i - 1], sa[i]
            a = (rank[prev], rank[prev + k] if prev + k < n else -1)
            b = (rank[cur], rank[cur + k] if cur + k < n else -1)
            tmp[cur] = tmp[prev] + (1 if a != b else 0)
        rank = tmp[:]
        if rank[sa[-1]] == n - 1:        # 모든 순위 유일 → 종료
            break
        k <<= 1
    return sa


def build_lcp(s: str, sa: list[int]) -> list[int]:
    n = len(s)
    rank = [0] * n
    for i, p in enumerate(sa):
        rank[p] = i
    lcp = [0] * n
    h = 0                                # Kasai: O(N)
    for i in range(n):
        if rank[i] > 0:
            j = sa[rank[i] - 1]
            while i + h < n and j + h < n and s[i + h] == s[j + h]:
                h += 1
            lcp[rank[i]] = h
            if h > 0:
                h -= 1                    # 다음 칸 재사용
        else:
            h = 0
    return lcp
```

## 부분 문자열 이분 탐색

```python
import bisect

def contains(s: str, sa: list[int], pattern: str) -> bool:
    suffixes = [s[i:] for i in sa]       # 개념용 (실제론 비교 함수로 처리)
    lo = bisect.bisect_left(
        range(len(sa)), True,
        key=lambda k: s[sa[k]:sa[k] + len(pattern)] >= pattern
    )
    return lo < len(sa) and s[sa[lo]:sa[lo] + len(pattern)] == pattern
# 정렬된 SA에서 접두사가 pattern인 구간 존재 여부 → O(M log N)
```

- 정렬돼 있으므로 패턴으로 시작하는 접미사들은 연속 구간 → 이분 탐색으로 경계 찾기
- 등장 횟수 → 좌·우 경계 두 번 이분 탐색해 구간 길이

## 서로 다른 부분 문자열 개수

- 전체 부분문자열 수 = `n(n+1)/2` (접미사들의 모든 접두사)
- 중복 = LCP 합 → 인접 접미사가 공유하는 접두사는 이미 센 것
- 정답 → `n(n+1)/2 - sum(lcp)`

```python
def distinct_substrings(s: str) -> int:
    n = len(s)
    sa = build_suffix_array(s)
    lcp = build_lcp(s, sa)
    return n * (n + 1) // 2 - sum(lcp)   # 백준 11479 계열
```

<Note type="warning" title="자주 하는 실수">
- 접미사를 문자열로 통째 정렬 → O(N²log N) 메모리·시간 폭발 → 순위 기반 정렬 사용
- LCP를 매번 직접 비교로 계산 → O(N²) → Kasai로 O(N)
- 검색 시 패턴 길이 초과 슬라이싱 경계 누락 → 인덱스 오류
- 서로 다른 부분문자열 → `n(n+1)/2`에서 `sum(lcp)` 빼는 것 · LCP[0] 미정의 주의
</Note>
