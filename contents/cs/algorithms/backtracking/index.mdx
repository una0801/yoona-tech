## 목적
- **상태 공간 트리**를 DFS로 탐색하며 **불가능한 분기(경로)** 를 조기에 차단하여 해를 찾음
- 순열/조합/부분집합, 배치/경로/퍼즐 등 **조합적 탐색 문제**를 체계적으로 해결
- **중복 제거** 규칙, **정렬·정규화(normalization)**, **제약 전파(constraint propagation)** 로 탐색 공간을 최소화
---
## 핵심정리
- 백트래킹 = ***선택 ➡️ 재귀 ➡️ 선택취소 ➡️ Pruning** 으로 상태 공간 탐색
- 중복 방지 : 정렬 + 인접 중복 Skip, visited/카운터, 순서 강제
- 전파와 휴리스틱(MRV/LCV)으로 탐색 트리플 급감
- 대표 문제 : 순열/조합/부분집합, Combination Sum, N-Queens, Sudoku
---
## 개념
- **Backtracking(백트래킹)**: **선택 ➡️ 재귀 호출 ➡️ 선택 취소(undo)** 를 반복하며 정답을 구성하는 DFS 탐색 기법
- **Pruning(가지치기)**: 제약 위반/불가능/열등한 경로를 **미리** 배제하여 지수적 공간을 줄이는 핵심 전략
- **상태(State)**: 현재까지의 부분해(예: path), 사용 여부(visited), 보조 정보(열/대각선 점유 등)
- **복잡도**: 제약과 차단이 없으면 보통 **지수 시간**(예: 순열 `O(n!)`, 부분집합 `O(2^n)`)
---
## 설계
1. 공통 패턴 (순열/조합/부분집합)
   ```python
   def backtrack(start_or_candidates):
    if 종료조건:
        ans.append(path.copy())
        return
    for 선택 in 가능한_선택들(start_or_candidates):
        if (제약 위반) or (중복 발생): 
            continue
        path.append(선택)         # 선택
        상태갱신(선택)            # 방문표시/카운터/용량 등
        backtrack(다음상태)        # 재귀
        상태복구(선택)            # undo
        path.pop()               # 선택 취소
   ```
2. 설계 포인트
   - 상태 정의 : `path`, `idx/start`,`visited`, 추가 제약 조건 (집합/비트마스크/카운터)
   - 종료 조건 : 길이/합/개수/모든 셀 채움 등 문제별 완성 조건
   - 차단(pruning) 규칙 :
     - 조기 탈락 : 합이 목표 초과, 남은 자원으로 목표 불가, 중복 값 skip
     - 제약 전파 : Sudoku의 행/열/박스 사용 여부, N-Queens의 열/대각선 점유
   - 중복 회피 :
     - 정렬 + 인정 중복 Skip : `if i>start and nums[i]==nums[i-1]: continue`
     - 사용 카운터 또는 visited + 값 기반 skip
     - 사전 순/고정 순서로 생성(조합은 `start` 부터만 순회)

## 예제
1. 부분 집합(모든 서브넷) - `O(2^n)`
   ```python
   def subsets(nums):
    nums.sort()
    ans, path = [], []
    def bt(i):
        ans.append(path.copy())
        for k in range(i, len(nums)):
            # (옵션) 중복 값이 있다면 조합형 중복 방지
            if k > i and nums[k] == nums[k-1]: 
                continue
            path.append(nums[k])
            bt(k+1)
            path.pop()
    bt(0)
    return ans
   ```
2. 순열 (모든 Permutation) - `O(n!)`
   ```python
   def permute(nums):
    ans, path = [], []
    used = [False]*len(nums)
    nums.sort()  # 중복 순열 방지용
    def bt():
        if len(path) == len(nums):
            ans.append(path.copy()); return
        for i in range(len(nums)):
            if used[i]: 
                continue
            # 같은 레벨에서 동일 값 중복 방지
            if i>0 and nums[i]==nums[i-1] and not used[i-1]:
                continue
            used[i] = True
            path.append(nums[i])
            bt()
            path.pop()
            used[i] = False
    bt()
    return ans
   ```
3. 조합 합(Combination Sum) - 정렬 + Pruning
   ```python
   def combination_sum(candidates, target):
    candidates.sort()
    ans, path = [], []
    def bt(start, remain):
        if remain == 0:
            ans.append(path.copy()); return
        for i in range(start, len(candidates)):
            c = candidates[i]
            if c > remain:      # pruning: 남은 합 초과
                break
            path.append(c)
            bt(i, remain - c)   # 같은 원소 재사용 가능 → i
            path.pop()
    bt(0, target)
    return ans
   ```
4. N-Queens - 제약 전파로 강력한 Pruning
   ```python
   def solveNQueens(n):
    cols, diag1, diag2 = set(), set(), set()  # 열, (r-c), (r+c)
    board = [["."]*n for _ in range(n)]
    ans = []
    def bt(r):
        if r == n:
            ans.append(["".join(row) for row in board]); return
        for c in range(n):
            if (c in cols) or ((r-c) in diag1) or ((r+c) in diag2):
                continue
            cols.add(c); diag1.add(r-c); diag2.add(r+c)
            board[r][c] = "Q"
            bt(r+1)
            board[r][c] = "."
            cols.remove(c); diag1.remove(r-c); diag2.remove(r+c)
    bt(0)
    return ans
   ```
5. Sudoku - 도메인 축소(가능 후보 캐시)로 전파 강화
   - 상태 : 빈 셀 목록, 각 셀의 후보 숫자 집합
   - 선택 전략 : 가장 후보가 적은 셀(MRV) 먼저 선택 -> 탐색 트리 급축소
   - 매 배치 시 행/열/박스 후보에서 제거 (전파), 되돌릴 땐 되복원(Undo)

## 실전 Pruning
- **정렬 후 탐색** : 조합/부분 집합에서 중복 제거/한계 초과 break
- **상한/하한 추정** : 남은 최대치로도 목표에 미달이면 중단(Branch and Bound)
- **도메인 축소** : 후보 리스트/비트마스크로 제약 전파
- **휴리스틱 선택** : MRV(후보 최소), LCV(가장 덜 제한적인 값)
- **조기 검증** : 제약 위반 즉시 Cotinue 
---
## 복잡도 및 비교
- 복잡도: 기본적으로 지수형 `(O(2^n), O(n!))`이나, 강한 Pruning 으로 실전 성능을 크게 개선
- DFS vs Backtracking: 백트래킹은 되돌리기(undo) + Pruning 규칙을 체계화한 DFS
- DP vs Backtracking:
   - DP: 중복 부분 문제 + 최적 부분 구조 ➡️ 테이블/메모이로 재사용
   - Backtracking: 정답(들) 생성/검증 중심, 최적화는 Branch & Bound/휴리스틱으로
