## 쿠버네티스란?
- 컨테이너화된 애플리케이션을 **자동으로 배포,확장,운영,복구**해주는 컨테이너 오케스트레이션 플랫폼
- 도커로 애플리케이션을 배포하면 다음과 같은 문제들 발생
  - 컨테이너가 많아지면 수동으로 관리 어려움
  - 서비스 디스커버리, 로드밸런싱, 자가복구, 오토스케일링 기능 필요
  - 복잡한 애플리케이션을 여러 노드에 배포하려면 자동화가 필요함

## 주요 기능
| 기능                      | 설명                               |
| ----------------------- | -------------------------------- |
| **자동 배포 및 롤백**          | 앱을 정의한 방식대로 자동 배포, 문제 발생 시 롤백 가능 |
| **로드밸런싱 & 서비스 디스커버리**   | 여러 Pod 간 트래픽 분산, 서비스 이름 기반 통신    |
| **오토스케일링**              | 리소스 사용량에 따라 Pod 수 자동 조절          |
| **자가 복구(Self-Healing)** | 실패한 컨테이너 자동 재시작 또는 교체            |
| **스토리지 관리**             | 로컬, NFS, 클라우드 등 다양한 스토리지 자동 마운트  |
| **비밀정보 & 설정 관리**        | 환경 변수, Secret 등을 안전하게 관리         |
---
## 구성요소
- Control Plane
  | 구성요소                   | 역할                        |
  | ---------------------- | ------------------------- |
  | **API Server**         | 모든 명령의 입구, REST API 처리    |
  | **etcd**               | 클러스터 상태 저장 (Key-Value DB) |
  | **Controller Manager** | 상태 유지 컨트롤러들 집합            |
  | **Scheduler**          | 새로 생성된 Pod를 적절한 노드에 배치    |
- Node(Worker)
  | 구성요소                  | 역할                              |
  | --------------------- | ------------------------------- |
  | **kubelet**           | 노드에서 Pod 상태 관리                  |
  | **kube-proxy**        | 서비스 트래픽 라우팅                     |
  | **Container Runtime** | Docker, containerd 등 컨테이너 실행 담당 |

## 핵심 개념 용어
| 용어                   | 설명                                    |
| -------------------- | ------------------------------------- |
| **Pod**              | 쿠버네티스에서 배포 가능한 최소 단위 (1개 이상의 컨테이너 포함) |
| **Deployment**       | Pod의 선언적 배포 방식, 롤링 업데이트 지원            |
| **Service**          | Pod 집합에 대한 네트워크 접근 포인트                |
| **Namespace**        | 클러스터 리소스를 논리적으로 분리하는 단위               |
| **ConfigMap/Secret** | 설정 값 및 민감 정보 관리                       |
