## 목적
- 탐색의 기본 개념 이해
- 선형 탐색과 이진탐색의 동작 원리와 복잡도 비교
- 탐색 알고리즘의 다양한 변형 기법을 학습하여 문제 상황에 맞게 선택
---
## 핵심정리
- 탐색의 핵심은 데이터 구조와 상황에 따라 알고리즘을 선택하는 것
- 선형 탐색: O(n), 단순
- 이진 탐색: O(log n), 정렬 필요
- 해시 탐색: 평균 O(1), 충돌 시 성능 저하
- 트리/그래프 탐색: 구조적 데이터 탐색에 최적화
---
## 개념
- **Searching(탐색)** : 데이터 집합에서 원하는 원소를 찾는 과정
- 주요 탐색 알고리즘
  - 선형 탐색 : 단순 순차 검사
  - 이진 탐색 : 정렬된 배열에서 절반씩 범위 축소
  - 그 외 해시기반 탐색, 트리탐색, 그래프 탐색(DFS,BFS) 등
---
## 선형탐색
- 동작 : 배열의 처음부터 끝까지 순차적으로 확인
- 시간복잡도 
  - 최선: O(1) (첫 원소가 목표일 때)  
  - 최악: O(n)
- 장점 : 구현이 단순, 정렬 불필요
- 단점 : 데이터가 많아질수록 비효율
- 사례 : 데이터 크기가 작거나 정렬이 보장되지 않은 경우
---
## 이진탐색
- 전제 조건 : 데이터가 **정렬**되어 있어야함
- 동작 원리
  1. 중간값(mid) 확인
  2. 목표값과 비교
  3. 크면 오른쪽, 작으면 왼쪽 절반으로 범위 축소
- 시간 복잡도 : O(log n)  
- 장점 : 큰 데이터셋에서도 매우 효율적
- 단점 : 정렬이 선행되어야함, 배열 인덱스 기반 탐색에 적합
- 사례 : 정렬된 배열/리스트에서 빠른 탐색 필요할 때
---
## 이진 탐색 변형
- Lower Bound : 특정 값 이상이 처음 나타나는 위치
- Upper Bound : 특정 값보다 큰 값이 처음 나타나는 위치
- Parametric Search : 조건을 만족하는 최소/최대 값을 찾을 때 활용(ex. 최소 시간, 최대 용량)
---
## 해시 탐색
- Hash Table 을 활용 ➡️ 평균 O(1), 최악 O(n)  
- 충돌 해결 기법에 따라 성능 좌우 (Chaining, Open Addressing 등)  
- 사례 : 키 기반 빠른 검색 필요 시
---
## 트리/그래프 탐색
- 이진 탐색 트리(BST): 평균 O(log n), 최악 O(n) (편향 트리)  
- 균형 트리(AVL, Red-Black): 항상 O(log n) 보장  
- DFS/BFS: 그래프 탐색에서 사용, 시간 O(V+E)  
- 사례 : 경로 탐색, 관계형 데이터 처리
---
## 예시
1. 선형 탐색
   ```python
   def linear_search(arr, target):
    for i, v in enumerate(arr):
        if v == target:
            return i
    return -1
   ```
2. 이진 탐색
   ```python
   def binary_search(arr, target):
    left, right = 0, len(arr)-1
    while left <= right:
        mid = (left+right)//2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            left = mid+1
        else:
            right = mid-1
    return -1
   ```
3. Lower Bound(python bisect 활용)
   ```python
   import bisect

    arr = [1, 2, 4, 4, 5, 7]
    x = 4
    print(bisect.bisect_left(arr, x))  # 2 (첫 4의 위치)
    print(bisect.bisect_right(arr, x)) # 4 (마지막 4 다음 위치)
   ```
