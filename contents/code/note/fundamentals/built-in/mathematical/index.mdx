## 절댓값 - abs(x)
- 주어진 숫자의 절댓값 반환
```python
abs(-5)    # 결과: 5
abs(3.14)  # 결과: 3.14
```

## 제곱 - pow(x, y[, z])
- x의 y제곱을 계산
- 세 번째 인자 z가 주어지면, 결과를 z로 나눈 나머지를 반환
```python
pow(2, 3)      # 결과: 8
pow(2, 3, 3)   # 결과: 2  (2^3 = 8, 8 % 3 = 2)
```

## 반올림 - round(x[, n])
- 숫자 x를 소수점 n 까지 반올림
- n의 기본값은 0
```python
round(3.14159, 2)  # 결과: 3.14
round(3.5)         # 결과: 4
```
