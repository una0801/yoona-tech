- **prefix sum**(누적합) → 0번부터 i번까지 더한 값을 **미리** 배열에 적어둠
- 한 번 적어두면 → 어떤 구간 합이든 **뺄셈 한 번**으로 O(1) 조회
- **difference array**(차분 배열) → 반대 발상 → 구간에 **한꺼번에 +값** 할 때 양 끝만 표시
- 둘 다 핵심은 → 매번 다시 더하지 말고 **미리 준비 / 나중에 한 번에 정산**

## 계단 오르며 층마다 합 적어두기

- 계단을 오르며 **그 층까지 올라온 칸 수**를 층마다 메모해 둔다고 상상
- 3층~7층 사이 칸 수가 궁금 → 다시 세지 않고 → `7층 메모 - 2층 메모` → 뺄셈 한 번
- 매번 처음부터 세면 구간마다 O(n) → 메모해두면 조회는 O(1)
- 차분은 거꾸로 → "5층부터 9층까지 다 +1" → 5층 입구에 +1, 10층 입구에 -1만 적어두고 → 나중에 누적합으로 한 번에 펼침

<KeyPoint title="이 비유에서 가져갈 것">
prefix sum = 미리 합을 적어두고 뺄셈으로 구간합 즉답 ·
difference array = 구간 업데이트를 양 끝 표시로 미뤄뒀다 누적합으로 한 번에 정산
</KeyPoint>

## 1D 누적합 배열 채우기

- 원본 `arr`, 누적합 `pre` → `pre[i] = pre[i-1] + arr[i-1]` → 한 칸씩 누적
- `pre[0] = 0` 더미 → 구간 `[l, r]` 합 = `pre[r+1] - pre[l]` (인덱스 깔끔)

- 원본 `arr = [3, 1, 4, 1, 5]` 일 때 채우는 과정

| step | i | 계산 | pre 배열 |
|------|---|------|----------|
| 시작 | - | 더미 0 | `[0]` |
| 1 | 0 | 0 + 3 | `[0, 3]` |
| 2 | 1 | 3 + 1 | `[0, 3, 4]` |
| 3 | 2 | 4 + 4 | `[0, 3, 4, 8]` |
| 4 | 3 | 8 + 1 | `[0, 3, 4, 8, 9]` |
| 5 | 4 | 9 + 5 | `[0, 3, 4, 8, 9, 14]` |

- 구간 `[1, 3]`(값 1,4,1) 합 → `pre[4] - pre[1]` = `9 - 3` = `6` → 뺄셈 한 번

```python
def build_prefix(arr):
    pre = [0] * (len(arr) + 1)        # 더미 한 칸 더
    for i in range(len(arr)):
        pre[i + 1] = pre[i] + arr[i]  # 앞 누적 + 현재
    return pre

def range_sum(pre, l, r):             # [l, r] 닫힌 구간
    return pre[r + 1] - pre[l]        # 뺄셈 한 번 → O(1)
```

- 빌드 O(n) 한 번 → 이후 조회 q번이 각각 O(1) → 총 O(n + q)
- 매번 다시 더하면 → O(n·q) → 조회 많을수록 누적합이 압도적

## 2D 누적합 - 지역 통계

- 표 형태 데이터(지역별 매출, 격자 픽셀) → 직사각형 구간 합도 O(1)
- `pre[i][j]` = (0,0)~(i-1,j-1) 직사각형 합 → 포함·배제 원리(inclusion-exclusion)

```python
def build_2d(grid):
    R, C = len(grid), len(grid[0])
    pre = [[0] * (C + 1) for _ in range(R + 1)]
    for i in range(R):
        for j in range(C):
            pre[i+1][j+1] = (grid[i][j]
                             + pre[i][j+1]   # 위
                             + pre[i+1][j]   # 왼쪽
                             - pre[i][j])    # 겹친 부분 빼기
    return pre

def rect_sum(pre, r1, c1, r2, c2):           # (r1,c1)~(r2,c2) 직사각형
    return (pre[r2+1][c2+1] - pre[r1][c2+1]
            - pre[r2+1][c1] + pre[r1][c1])
```

<Note type="note" title="포함·배제 한 줄">
- 큰 사각형 → 위 띠 빼고 → 왼쪽 띠 빼면 → 모서리(겹친 칸)가 두 번 빠짐 → 다시 한 번 더해 복구
</Note>

## 차분 배열 - 구간 한꺼번에 더하기

- 상황 → "3~6번 손님에게 쿠폰 +5", "2~9번 좌석에 +1" 같은 **구간 업데이트** 다발
- 매 업데이트마다 구간 전체를 돌면 → 업데이트당 O(n)
- 차분 → 구간 `[l, r]`에 `+v` → `diff[l] += v`, `diff[r+1] -= v` → 업데이트당 O(1)
- 모든 업데이트 끝난 뒤 → `diff` 누적합 한 번 → 최종 배열 복원

- `arr = [0,0,0,0,0]` 에 `[1,3] +2`, `[0,2] +1` 적용 과정

| step | 동작 | diff 배열 |
|------|------|-----------|
| 시작 | - | `[0,0,0,0,0,0]` |
| 1 | `[1,3]+2` → diff[1]+2, diff[4]-2 | `[0,2,0,0,-2,0]` |
| 2 | `[0,2]+1` → diff[0]+1, diff[3]-1 | `[1,2,0,-1,-2,0]` |
| 누적 | prefix sum 펼침 | `[1,3,3,2,0]` → 최종 결과 |

```python
def apply_ranges(n, updates):            # updates: (l, r, v)
    diff = [0] * (n + 1)
    for l, r, v in updates:
        diff[l] += v                     # 구간 시작에 +v
        diff[r + 1] -= v                 # 구간 끝 다음에 -v
    res = [0] * n
    acc = 0
    for i in range(n):
        acc += diff[i]                   # 누적합으로 펼치기
        res[i] = acc
    return res
```

<Note type="pink" title="언제 무엇을">
- 배열 **안 바뀌고** 구간합 조회만 많음 → prefix sum
- 구간 **업데이트** 다발 + 마지막에 결과 한 번 → difference array
- 2D 격자 직사각형 합·지역별 누적 통계 → 2D prefix sum
- 조회·업데이트가 **번갈아** 섞임 → prefix/diff 한계 → Fenwick(BIT)·세그먼트 트리
</Note>
