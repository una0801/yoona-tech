## 개념

| ORM | 설명 |
|------|------|
| **SQLAlchemy Async** | SQLAlchemy의 공식 비동기 지원 버전 (`async_engine` 사용) |
| **TortoiseORM** | Django ORM 스타일의 비동기 ORM (`asyncpg` 지원) |

- **비동기 ORM이 필요한 이유**
  - 기존 SQLAlchemy ORM은 **동기(Synchronous) 방식**으로 동작 → FastAPI의 **비동기 요청 처리에 적합하지 않음**.
  - **비동기 ORM을 사용하면** 데이터베이스 I/O가 블로킹되지 않아 **더 많은 요청을 효율적으로 처리 가능**.

  <TabsContent value="setup">
    ### ✅ 1. SQLAlchemy Async 설치
    ```bash
    pip install sqlalchemy aiosqlite asyncpg
    ```
    - `aiosqlite`: SQLite 비동기 드라이버  
    - `asyncpg`: PostgreSQL 비동기 드라이버  
  </TabsContent>

  <TabsContent value="engine">
    ### ✅ 2. 비동기 데이터베이스 엔진 설정
    ```python
    from sqlalchemy.ext.asyncio import AsyncSession, create_async_engine
    from sqlalchemy.orm import sessionmaker

    DATABASE_URL = "postgresql+asyncpg://user:password@localhost/dbname"

    engine = create_async_engine(DATABASE_URL, echo=True)
    async_session = sessionmaker(engine, class_=AsyncSession, expire_on_commit=False)

    async def get_db():
        async with async_session() as session:
            yield session
    ```
    - `create_async_engine()`을 사용하여 **비동기 데이터베이스 엔진을 생성**.
    - `async_session`을 FastAPI의 **의존성 주입(Dependency Injection)**에 활용 가능.
  </TabsContent>

  <TabsContent value="models">
    ### ✅ 3. SQLAlchemy 비동기 모델 정의
    ```python
    from sqlalchemy.ext.declarative import declarative_base
    from sqlalchemy import Column, Integer, String

    Base = declarative_base()

    class User(Base):
        __tablename__ = "users"
        id = Column(Integer, primary_key=True, index=True)
        name = Column(String, index=True)
        email = Column(String, unique=True, index=True)
    ```
    - 기존 SQLAlchemy 모델과 유사하지만 **비동기 세션을 사용해야 함**.
  </TabsContent>

  <TabsContent value="crud">
    ### ✅ 4. 비동기 CRUD 연동 (FastAPI)
    ```python
    from fastapi import FastAPI, Depends
    from sqlalchemy.ext.asyncio import AsyncSession
    from sqlalchemy.future import select

    app = FastAPI()

    @app.get("/users")
    async def get_users(db: AsyncSession = Depends(get_db)):
        result = await db.execute(select(User))
        return result.scalars().all()
    ```
    - `await db.execute(select(User))`을 사용하여 **비동기적으로 데이터 조회**.
    - FastAPI의 **의존성 주입(Depends)**을 통해 **비동기 세션을 주입**.

  </TabsContent>
</Tabs>

## TortoiseORM 연동하기

<Tabs defaultValue="setup">
  <TabsList>
    <TabsTrigger value="setup">설치/환경</TabsTrigger>
    <TabsTrigger value="models">모델정의</TabsTrigger>
    <TabsTrigger value="init">FastAPI연동</TabsTrigger>
    <TabsTrigger value="crud">CRUD연동</TabsTrigger>
  </TabsList>

  <TabsContent value="setup">
    ### ✅ 1. TortoiseORM 설치
    ```bash
    pip install tortoise-orm asyncpg
    ```
    - `asyncpg`: PostgreSQL 비동기 드라이버  
    - `tortoise-orm`: Django 스타일의 ORM (비동기 지원)
  </TabsContent>

  <TabsContent value="models">
    ### ✅ 2. TortoiseORM 모델 정의
    ```python
    from tortoise.models import Model
    from tortoise import fields

    class User(Model):
        id = fields.IntField(pk=True)
        name = fields.CharField(max_length=50)
        email = fields.CharField(max_length=100, unique=True)
    ```
    - SQLAlchemy보다 **더 직관적인 모델 정의 방식**.
  </TabsContent>

  <TabsContent value="init">
    ### ✅ 3. FastAPI에서 TortoiseORM 초기화
    ```python
    from tortoise.contrib.fastapi import register_tortoise

    app = FastAPI()

    register_tortoise(
        app,
        db_url="postgres://user:password@localhost/dbname",
        modules={"models": ["models"]},
        generate_schemas=True,
        add_exception_handlers=True,
    )
    ```
    - `register_tortoise()`를 사용하여 **FastAPI에 TortoiseORM을 연동**.
  </TabsContent>

  <TabsContent value="crud">
    ### ✅ 4. 비동기 CRUD 연동 (FastAPI)
    ```python
    @app.get("/users")
    async def get_users():
        return await User.all()  # 비동기 데이터 조회
    ```
    - SQLAlchemy보다 **더 간단한 비동기 CRUD API**를 제공.

  </TabsContent>
</Tabs>

## 비교

| 비교 항목 | **SQLAlchemy Async** | **TortoiseORM** |
|-----------|----------------|----------------|
| 사용 방식 | SQLAlchemy 공식 ORM | Django 스타일 ORM |
| 비동기 지원 | ✅ 지원 (async_session 사용) | ✅ 지원 (내장 지원) |
| 쿼리 방식 | `await session.execute(select(User))` | `await User.all()` |
| 학습 난이도 | 🔵 (어려움) | 🟢 (쉬움) |
| 성능 | 고성능 | 고성능 |

📌 **SQLAlchemy Async**: 기존 SQLAlchemy 사용자가 **비동기 환경에서도 활용 가능**  
📌 **TortoiseORM**: Django ORM과 비슷한 **더 직관적인 비동기 ORM**
