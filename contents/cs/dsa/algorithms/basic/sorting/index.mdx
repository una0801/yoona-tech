## 개념
- 정렬(Sorting)이란 데이터를 특정한 순서대로 나열하는 과정
  - 데이터 크기가 작을 경우 → 선택 정렬, 삽입 정렬
  - 데이터 크기가 클 경우 → 퀵 정렬, 병합 정렬, 힙 정렬
  - 숫자 범위가 좁은 경우 → 계수 정렬, 기수 정렬
- **비교 기반 정렬**과 **비비교 기반 정렬**로 나뉨

| 알고리즘 | 평균 시간 복잡도 | 최악 시간 복잡도 | 공간 복잡도 | 특징 |
|----------|----------------|----------------|-------------|------|
| **버블 정렬** (Bubble Sort) | O(N²) | O(N²) | O(1) | 가장 단순하지만 비효율적 |
| **선택 정렬** (Selection Sort) | O(N²) | O(N²) | O(1) | 데이터 크기가 적을 때 사용 가능 |
| **삽입 정렬** (Insertion Sort) | O(N²) | O(N²) | O(1) | 거의 정렬된 데이터에서 유용 |
| **병합 정렬** (Merge Sort) | O(N log N) | O(N log N) | O(N) | 안정 정렬, 분할 정복 방식 |
| **퀵 정렬** (Quick Sort) | O(N log N) | O(N²) | O(log N) | 가장 빠른 정렬 중 하나, 불안정 정렬 |
| **힙 정렬** (Heap Sort) | O(N log N) | O(N log N) | O(1) | 힙 자료구조 기반 |
| **계수 정렬** (Counting Sort) | O(N + K) | O(N + K) | O(K) | 숫자 범위가 작을 때 유용 |
| **기수 정렬** (Radix Sort) | O(NK) | O(NK) | O(N + K) | 숫자 기반 정렬 |

## 버블 정렬
- 인접한 두 개의 데이터를 비교하여 정렬하는 가장 단순한 방법
- 시간 복잡도: `O(N²)` (매우 비효율적)
```python
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        for j in range(n - i - 1):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
    return arr

arr = [5, 3, 8, 1, 2]
print(bubble_sort(arr))  # [1, 2, 3, 5, 8]
```

## 선택 정렬
- 가장 작은 값을 찾아서 차례로 정렬하는 방식
- 시간 복잡도: `O(N²)` (큰 데이터에는 비효율적)
```python
def selection_sort(arr):
    n = len(arr)
    for i in range(n):
        min_idx = i
        for j in range(i + 1, n):
            if arr[j] < arr[min_idx]:
                min_idx = j
        arr[i], arr[min_idx] = arr[min_idx], arr[i]
    return arr

arr = [29, 10, 14, 37, 13]
print(selection_sort(arr))  # [10, 13, 14, 29, 37]
```

## 삽입 정렬
- 이미 정렬된 부분에 새로운 데이터를 삽입하는 방식
- 시간 복잡도: `O(N²)`, 거의 정렬된 데이터에서 `O(N)`
```python
def insertion_sort(arr):
    for i in range(1, len(arr)):
        key = arr[i]
        j = i - 1
        while j >= 0 and arr[j] > key:
            arr[j + 1] = arr[j]
            j -= 1
        arr[j + 1] = key
    return arr

arr = [9, 5, 1, 4, 3]
print(insertion_sort(arr))  # [1, 3, 4, 5, 9]
```
## 병합 정렬
- 데이터를 반씩 나누어 정렬 후 합치는 방식(분할 정복)
- 시간 복잡도: `O(N log N)` (안정 정렬)
```python
def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    return merge(left, right)

def merge(left, right):
    sorted_arr = []
    i = j = 0
    while i < len(left) and j < len(right):
        if left[i] < right[j]:
            sorted_arr.append(left[i])
            i += 1
        else:
            sorted_arr.append(right[j])
            j += 1
    sorted_arr.extend(left[i:])
    sorted_arr.extend(right[j:])
    return sorted_arr

arr = [6, 3, 8, 5, 2]
print(merge_sort(arr))  # [2, 3, 5, 6, 8]
```
## 퀵 정렬
- 기준(pivot)을 정하고 정렬하는 방식 (가장 빠름, 불안정 정렬)
- 시간 복잡도: 평균 `O(N log N)`, 최악 `O(N²`)
```python
def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quick_sort(left) + middle + quick_sort(right)

arr = [10, 7, 8, 9, 1, 5]
print(quick_sort(arr))  # [1, 5, 7, 8, 9, 10]
```

## 힙 정렬
- 힙(Heap) 자료구조를 이용한 정렬 알고리즘
  - 힙은 완전 이진 트리(Complete Binary Tree) 형태의 자료구조다.
  - 최대 힙(Max Heap)은 부모 노드가 자식 노드보다 항상 크다.
  - 최소 힙(Min Heap)은 부모 노드가 자식 노드보다 항상 작다.
  - **힙을 이용해 최댓값 또는 최솟값을 빠르게 찾아 정렬할 수 있다.**
- 최대 힙 또는 최소 힙 활용
- 시간 복잡도: `O(N log N)` (모든 경우에 일정한 성능) 
- 공간 복잡도 : `O(1)` (제자리 정렬)``
```python
import heapq

def heap_sort(arr):
    heap = []
    for num in arr:
        heapq.heappush(heap, num)
    sorted_arr = [heapq.heappop(heap) for _ in range(len(arr))]
    return sorted_arr

arr = [5, 3, 8, 1, 2]
print(heap_sort(arr))  # [1, 2, 3, 5, 8]
````

## 계수 정렬
- 특정 범위 내에서 숫자의 개수를 세어 정렬하는 알고리즘
  - 데이터의 크기가 한정된 범위(0~K)일 때, 매우 빠르게 정렬 가능.
  - 숫자의 개수를 카운트하여 정렬하는 방식.
  - 정수형 데이터에서만 사용 가능하며, 실수나 문자열 데이터는 불가능.
- 비교 연산 없이 정렬이 가능
- 시간 복잡도: `O(N + K)` (N: 입력 크기, K: 데이터 범위)
- 공간 복잡도: `O(K)` (데이터 범위가 크면 메모리 낭비 발생)
```python
✅ 데이터 크기가 작을 때 효율적
❌ 숫자 범위가 클 경우 메모리 낭비가 심함

def counting_sort(arr):
    max_value = max(arr)
    count = [0] * (max_value + 1)

    for num in arr:
        count[num] += 1

    sorted_arr = []
    for num, freq in enumerate(count):
        sorted_arr.extend([num] * freq)

    return sorted_arr

arr = [4, 2, 2, 8, 3, 3, 1]
print(counting_sort(arr))  # [1, 2, 2, 3, 3, 4, 8]
```
## 기수 정렬
- 숫자의 자리수를 기준으로 정렬하는 알고리즘
  - 가장 낮은 자리수(LSD)부터 높은 자리수까지 정렬.
  - 각 자리수의 숫자를 기준으로 계수 정렬(Counting Sort) 사용.
  - 비교 기반 정렬이 아니므로 O(N log N)보다 빠를 수 있음.
- LSD (Least Significant Digit) 방식 사용
- 시간 복잡도: `O(NK)` (N: 입력 크기, K: 자릿수)
- 공간 복잡도: `O(N + K)` (보조 배열 필요)
```python
✅ 정수형 데이터에서만 사용 가능
✅ 데이터 크기가 작고, 범위가 넓을 때 유리
❌ 실수, 문자열 정렬에는 적합하지 않음

def radix_sort(arr):
    max_num = max(arr)
    exp = 1

    while max_num // exp > 0:
        counting_sort_radix(arr, exp)
        exp *= 10

def counting_sort_radix(arr, exp):
    output = [0] * len(arr)
    count = [0] * 10

    for num in arr:
        index = (num // exp) % 10
        count[index] += 1

    for i in range(1, 10):
        count[i] += count[i - 1]

    for i in range(len(arr) - 1, -1, -1):
        index = (arr[i] // exp) % 10
        output[count[index] - 1] = arr[i]
        count[index] -= 1

    for i in range(len(arr)):
        arr[i] = output[i]

arr = [170, 45, 75, 90, 802, 24, 2, 66]
radix_sort(arr)
print(arr)  # [2, 24, 45, 66, 75, 90, 170, 802]
```
