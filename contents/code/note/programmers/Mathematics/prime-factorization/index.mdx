title: 소인수분해

## 문제
```
소인수분해란 어떤 수를 소수들의 곱으로 표현하는 것입니다. 
예를 들어 12를 소인수 분해하면 2 * 2 * 3 으로 나타낼 수 있습니다. 
따라서 12의 소인수는 2와 3입니다. 
자연수 n이 매개변수로 주어질 때 n의 소인수를 오름차순으로 담은 배열을 return하도록 solution 함수를 완성해주세요.

✅ 제한사항
2 ≤ n ≤ 10,000

✅ 입출력 예 설명
- 입출력 예 #1
    12를 소인수분해하면 2 * 2 * 3 입니다. 따라서 [2, 3]을 return합니다.
- 입출력 예 #2
    17은 소수입니다. 따라서 [17]을 return 해야 합니다.
- 입출력 예 #3
    420을 소인수분해하면 2 * 2 * 3 * 5 * 7 입니다. 따라서 [2, 3, 5, 7]을 return합니다.
````

## 풀이*
- 소인수분해를 통해 n의 소인수를 찾으려면, **작은 소수부터** 차례대로 n을 나누면서 더 이상 나눌 수 없을 때까지 반복
- 이때 중복된 소인은 한 번만 담아야 하므로, 결과 리스트에 해당 소수가 이미 포함되어 있는지 확인하거나, 나눈 후 소인을 담는 방식으로 진행
-  ex) n = 12인 경우:
   - 2로 나누면 12 % 2 == 0 → 12 // 2 = 6, 결과에 2 추가
   - 다시 2로 나누면 6 % 2 == 0 → 6 // 2 = 3, 이미 결과에 2가 있으므로 추가하지 않음
   - 2로 나눌 수 없으므로 3으로 넘어가서 3 % 3 == 0 → 3 // 3 = 1, 결과에 3 추가
   - n이 1이 되어 종료
```python
def solution(n):
    factors = [] # n의 소인수를 저장할 리스트
    divisor = 2 # 2부터 시작해서 n을 나눌 소수
    
    while n >= divisor:
        if n % divisor == 0:  # divisor로 나누어 떨어지면
            if divisor not in factors:  # 중복되지 않게 추가
                factors.append(divisor)
            n //= divisor
        else:
            divisor += 1  # 나누어 떨어지지 않으면 divisor 증가
    return factors

# 예시 출력
print(solution(12))   # [2, 3]
print(solution(17))   # [17]
print(solution(420))  # [2, 3, 5, 7]
```
