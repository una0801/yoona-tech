## 문제
```
문자열 s가 매개변수로 주어집니다. 
s에서 한 번만 등장하는 문자를 사전 순으로 정렬한 문자열을 return 하도록 solution 함수를 완성해보세요. 
한 번만 등장하는 문자가 없을 경우 빈 문자열을 return 합니다.

✅ 제한사항
0 < s의 길이 < 1,000
s는 소문자로만 이루어져 있습니다.

✅ 입출력 예 설명
- 입출력 예 #1
    "abcabcadc"에서 하나만 등장하는 문자는 "d"입니다.
- 입출력 예 #2
    "abdc"에서 모든 문자가 한 번씩 등장하므로 사전 순으로 정렬한 "abcd"를 return 합니다.
- 입출력 예 #3
    "hello"에서 한 번씩 등장한 문자는 "heo"이고 이를 사전 순으로 정렬한 "eho"를 return 합니다.
```

## 풀이
- 빈도 계산: 문자열의 각 문자가 몇 번 등장하는지 딕셔너리(혹은 해시맵)를 이용해서 계산
- 필터링: 등장 횟수가 1인 문자만 리스트에 저장
- 정렬: 리스트에 저장된 문자들을 사전 순으로 정렬
- 문자열 변환: 정렬된 리스트를 다시 문자열로 변환
```python
def solution(s):
    # 각 문자의 등장 횟수를 딕셔너리로 계산
    freq = {}
    for char in s:
        freq[char] = freq.get(char, 0) + 1
        
    # 한 번만 등장한 문자들을 모으기
    unique_chars = [char for char, count in freq.items() if count == 1]
    
    # 사전순으로 정렬하여 문자열로 합치기
    return ''.join(sorted(unique_chars))
```
