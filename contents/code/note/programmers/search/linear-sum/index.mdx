## 문제
```
문자열 my_string이 매개변수로 주어집니다. 
my_string안의 모든 자연수들의 합을 return하도록 solution 함수를 완성해주세요.

✅ 제한사항
- 1 ≤ my_string의 길이 ≤ 1,000
- my_string은 소문자, 대문자 그리고 한자리 자연수로만 구성되어있습니다.

✅ 입출력 예 설명
- 입출력 예 #1
    "aAb1B2cC34oOp"안의 한자리 자연수는 1, 2, 3, 4 입니다. 따라서 1 + 2 + 3 + 4 = 10 을 return합니다.
- 입출력 예 #2
    "1a2b3c4d123Z"안의 한자리 자연수는 1, 2, 3, 4, 1, 2, 3 입니다. 따라서 1 + 2 + 3 + 4 + 1 + 2 + 3 = 16 을 return합니다.
```

## 풀이
- 문자열의 각 문자를 순회하며, 해당 문자가 숫자인지 확인한 후 숫자라면 정수로 변환하여 더해줌
```python
# isdigit() 함수는 파이썬의 문자열 메서드 중 하나로, 
# 해당 문자열이 숫자(0~9)로만 구성되어 있는지를 판단
def solution(my_string):
    total = 0
    for ch in my_string:
        if ch.isdigit():  
            total += int(ch)
    return total

# 예외처리를 활용한 방법(문자열 에러 예외처리)
def solution(my_string):
    answer = 0
    for i in my_string:
        try:
            answer = answer + int(i)
        except:
            pass

    return answer
```
