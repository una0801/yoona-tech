## 객체 길이 - len(s)
- 객체 s의 길이(요소의 개수)를 반환
```python
len([1, 2, 3])  # 결과: 3
len("hello")    # 결과: 5
```
---
## 숫자 시퀀스 - range()
- `range([start], stop[, step])`
- 숫자 시퀀스를 생성하는 이터러블 객체를 반환
```python
list(range(5))         # 결과: [0, 1, 2, 3, 4]
list(range(2, 10, 2))    # 결과: [2, 4, 6, 8]
```
---
## enumerate()
- `enumerate(iterable, start=0)`
- 이터러블 객체의 요소와 함께 인덱스(기본값은 0)를 포함하는 iterator를 반환
```python
for index, value in enumerate(["a", "b", "c"], start=1):
    print(index, value)
# 출력:
# 1 a
# 2 b
# 3 c
```
---
## zip()
- `zip(*iterables)`
- 여러 이터러블 객체의 요소들을 병렬로 묶어 튜플 형태로 반환하는 iterator를 생성
```python
list(zip([1, 2, 3], ["a", "b", "c"]))
# 결과: [(1, 'a'), (2, 'b'), (3, 'c')]
```
---
## 정렬 - sorted()
- `sorted(iterable, *, key=None, reverse=False)`
- 이터러블 객체의 정렬된 복사본을 리스트로 반환
```python
sorted([3, 1, 2])  # 결과: [1, 2, 3]
```
---
## 최대최소
- `min(iterable, *[, key, default])`
- `max(iterable, *[, key, default])`
- 이터러블 객체에서 최소값 또는 최대값을 반환
```python
min(5, 2, 9)      # 결과: 2
max([1, 2, 3])    # 결과: 3
```
---
## 합 - sum()
- `sum(iterable, start=0)`
- 이터러블 객체의 모든 요소를 누적하여 합계를 반환
```python
sum([1, 2, 3, 4])  # 결과: 10
```

## slice
- 리스트, 문자열, 튜플 같은 **시퀀스**에서 원하는 부분 추출
- `sequence[start:stop:step]`
  - start : 슬라이스의 시작 인덱스(포함), 생략시 처음부터 시작
  - stop : 슬라이스의 종료 인덱스(포함x), 생략시 끝까지
  - step: 인덱스의 증가(혹은 감소) 간격, 기본 값 = 1
```python
✅ 리스트 슬라이싱
numbers = [0, 1, 2, 3, 4, 5]
slice_example = numbers[1:4]  # 결과: [1, 2, 3]

✅ 문자열 슬라이싱
text = "Hello, World!"
slice_example = text[7:12]  # 결과: "World"

✅ 튜플 슬라이싱
coordinates = (10, 20, 30, 40, 50)
slice_example = coordinates[1:4]  # 결과: (20, 30, 40)
```
- step 매개변수 사용 : 요소들을 건너띄며 슬라이싱 가능
```python
numbers = [0, 1, 2, 3, 4, 5, 6]
slice_example = numbers[1:6:2]  # 결과: [1, 3, 5]

✅ 음수 사용 시 시퀀스를 역순으로 슬라이싱 가능
text = "Python"
reversed_text = text[::-1]  # 결과: "nohtyP"
```
- 음수 인덱스 사용 : 시퀀스의 끝에서부터 요소에 접근 가능
```python
text = "Python"
slice_example = text[-4:-1]  # 결과: "tho"
```
- 예제 : 리스트를 청크(조각)로 나누기
```python
def chunk_list(lst, n):
    # lst[i:i+n] 는 인덱스 i부터 n개의 요소를 추출합니다.
    return [lst[i:i+n] for i in range(0, len(lst), n)]

num_list = [1, 2, 3, 4, 5, 6, 7, 8]
result = chunk_list(num_list, 2)  
# 결과: [[1, 2], [3, 4], [5, 6], [7, 8]]
```
