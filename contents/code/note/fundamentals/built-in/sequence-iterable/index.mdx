## 객체 길이 - len(s)
- 객체 s의 길이(요소의 개수)를 반환
```python
len([1, 2, 3])  # 결과: 3
len("hello")    # 결과: 5
```
---
## 숫자 시퀀스 - range()
- `range([start], stop[, step])`
- 숫자 시퀀스를 생성하는 이터러블 객체를 반환
```python
list(range(5))         # 결과: [0, 1, 2, 3, 4]
list(range(2, 10, 2))    # 결과: [2, 4, 6, 8]
```
---
## enumerate()
- `enumerate(iterable, start=0)`
- 이터러블 객체의 요소와 함께 인덱스(기본값은 0)를 포함하는 iterator를 반환
```python
for index, value in enumerate(["a", "b", "c"], start=1):
    print(index, value)
# 출력:
# 1 a
# 2 b
# 3 c
```
---
## zip()
- `zip(*iterables)`
- 여러 이터러블 객체의 요소들을 병렬로 묶어 튜플 형태로 반환하는 iterator를 생성
```python
list(zip([1, 2, 3], ["a", "b", "c"]))
# 결과: [(1, 'a'), (2, 'b'), (3, 'c')]
```
---
## 정렬 - sorted()
- `sorted(iterable, *, key=None, reverse=False)`
- 이터러블 객체의 정렬된 복사본을 리스트로 반환
```python
sorted([3, 1, 2])  # 결과: [1, 2, 3]
```
---
## 최대최소
- `min(iterable, *[, key, default])`
- `max(iterable, *[, key, default])`
- 이터러블 객체에서 최소값 또는 최대값을 반환
```python
min(5, 2, 9)      # 결과: 2
max([1, 2, 3])    # 결과: 3
```
---
## 합 - sum()
- `sum(iterable, start=0)`
- 이터러블 객체의 모든 요소를 누적하여 합계를 반환
```python
sum([1, 2, 3, 4])  # 결과: 10
```
