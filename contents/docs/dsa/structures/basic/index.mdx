## 기본 개념

1️⃣ 자료구조란? 

데이터를 표현하고 관리하고 처리하기 위한 구조

2️⃣ 목적
  <ul><li>수 많은 자료(data)의 조직화를 통한 효율적인 저장, 관리</li></ul>
  <ul><li>효율적인 메모리 사용</li></ul>
  <ul><li>다양한 자료구조가 존재하지만 모든 목적에 적합한 만능의 단일 자료 구조는 없음</li></ul>
  <ul><li>삽입, 삭제, 비교, 교환, 검색 등의 자료 특성을 고려해 가장 효율적인 자료구조를 선택해야함</li></ul>

3️⃣ 분류
<ul>
  <li>
    <strong>선형구조</strong>
    <ul>
      <li>배열 (Array)</li>
      <li>연결 리스트 (Linked List)</li>
      <li>스택 (Stack)</li>
      <li>큐 (Queue)</li>
      <li>덱 (Deque)</li>
    </ul>
  </li>
  <li>
    <strong>비선형구조</strong>
    <ul>
      <li>
        <strong>트리 (Tree)</strong>
        <ul>
          <li>이진 트리 (Binary Tree)</li>
          <li>이진 탐색 트리 (BST)</li>
        </ul>
      </li>
      <li>
        <strong>그래프 (Graph)</strong>
        <ul>
          <li>방향 그래프 (Directed Graph)</li>
          <li>무방향 그래프 (Undirected Graph)</li>
        </ul>
      </li>
    </ul>
  </li>
</ul>
